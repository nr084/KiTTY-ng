# Вкладки сеансов — Windows, Linux и macOS

[Документация](README.md) · [English](tabs.en.md)

Начиная с KiTTY-ng 0.85-7 команда **«Дублировать сеанс»** открывает независимое подключение в новой вкладке текущего окна. При одном сеансе полоса вкладок скрыта; при появлении второго отображается сверху. Закрытие вкладки не завершает соседние подключения.

- Активная вкладка выделена голубым цветом; длинное название сокращается многоточием.
- Для изменения порядка перетащите вкладку мышью или нажмите правой кнопкой и выберите **«Переместить влево» / «Переместить вправо»**.
- Круг с белым крестиком (в 0.85-8 серый, красный при наведении) справа закрывает только эту вкладку. То же делает **«Закрыть вкладку»** в её контекстном меню. Подтверждение при этих действиях не запрашивается, даже если в настройках сеанса оно включено.
- При закрытии всего окна настройка подтверждения продолжает действовать.
- После закрытия предпоследнего сеанса полоса снова скрывается.

## Дублирование в 0.85-8

Правой кнопкой на нужной вкладке → **«Дублировать сеанс»**. Необязательно сначала переключаться на неё. Если исходный SSH-сеанс авторизован, копия использует его введённый пароль или парольную фразу ключа. Данные остаются только в памяти, не сохраняются в Sessions и не передаются через командную строку. Ключ и агент используются согласно настройкам сеанса. При отклонении повторной авторизации появится обычный запрос; одноразовые коды и серверные интерактивные ответы не повторяются.

## Отключение

Вкладки включены по умолчанию. Чтобы команда дублирования открывала отдельные окна, добавьте в `kitty.ini` портативного каталога:

```ini
[KiTTY]
SessionTabs=0
```

`SessionTabs=1` включает вкладки. Отсутствие ключа означает включённое состояние. Настройку применяйте перед открытием нового окна. Формат сохранённых сеансов не меняется.

macOS использует отдельную нативную реализацию AppKit с теми же правилами. Полоса вкладок прокручивается горизонтально, если все вкладки не помещаются. Параметры, терминал, прокрутка и SSH-подключение каждой вкладки независимы. Быстрые подключения при дублировании остаются временными. Верхнее меню «Сеанс» действует на активную вкладку.
