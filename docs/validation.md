# Проверки 0.85-6 — Windows, Linux и macOS

Windows x64/x86/ARM64 собраны локально на Windows стабильным LLVM-MinGW 20261006 (Clang 23.1.3). Нативные проверки x64/x86 пройдены; ARM64 проверена по PE/версии, повторный запуск на ARM64 в этой итерации не выполнялся.

Linux x86_64 собран на Windows и проверен в Ubuntu 26.04 с Xfce/X11 обычным пользователем: быстрое подключение SSH без сохранения профиля/пароля, загрузка/скачивание и drag-and-drop, автоматические команды, сочетания клавиш, блокировка ввода, Shift+стрелки в Midnight Commander, переподключение. Проверки браузера охватывают RU/EN, SSH/22, отмену, создание/дублирование и сохранение неизвестных полей. Скриншоты Windows/Linux обновлены с синтетическими данными.

macOS 0.85-6 собирается и проверяется на настоящем Mac: Universal 2, LLVM 23.1.3, arm64 и x86_64 через Rosetta. Нативные unit/AppKit/CLI, ключи и SSH/SCP/SFTP прошли для 0.85-6. В GUI проверены Cmd+C/V/X/A, защищённая вставка, быстрое подключение без записи профилей, отмена/неверный порт/дублирование и минимальный размер RU/EN; обновлены четыре Mac-снимка. Найден и исправлен перевод заголовка меню редактирования. [Подробный отчёт](macos-native-validation.md) и [обратная передача Windows](releases/0.85-6-windows-return.md). Все шесть пакетов 0.85-6 опубликованы из согласованного коммита `b95f861c7425b1d8c493c6bce9ba492d3a87161a`; контрольные суммы проверены после загрузки на GitHub. Ниже сохранена история 0.85-5.

# Область проверки 0.85-5

[Документация](README.md) · [Сборка](build.md) · [Следующие проверки](planned.md)

Исходный выпуск собирался локально на Windows. Mac-пакет 0.85-5 обновлён нативной сборкой **на Mac** компилятором LLVM 23.1.3; отчёты находятся в `dist/macos-native`. Версия и исходный тег сохранены, Windows/Linux-вложения не изменены. Linux-виртуальная машина используется для целевых библиотек и нативных проверок. [Подробный отчёт macOS](macos-native-validation.md).

| Проверка | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Архитектуры | x64, x86, ARM64 | Universal 2: ARM64 + Intel, все шесть файлов | x86_64, glibc 2.35 |

ARM64 Windows ранее подтверждён пользователем; обновлённые бинарники отдельно проверены по структуре PE. Linux Wayland, ARM64 и другие дистрибутивы, физический Mac Intel/macOS 13, Kerberos/GSSAPI с действующими credentials не заявлены как проверенные.

Windows не подписан Authenticode; macOS использует ad-hoc подпись, без Apple notarization. Сохранённый пароль KiTTY — совместимый обратимый формат, а не защищённое хранилище.
