# Проверки Windows/Linux 0.85-11

Windows: локальная сборка LLVM-MinGW 20261020 / Clang 23.1.4, официальный stable проверен перед сборкой. x64/x86 проверяются нативно; ARM64 — структура и версия всех шести PE-файлов. Новый нативный запуск Windows ARM64 не заявляется.

Изменённые сценарии охватывают реальный клавиатурный ввод RU/EN, переключение вкладок и Alt+Tab, значок окна, повторный фокус флажков без повреждения подписи, отключение и явный перезапуск, несохранённое подключение с защищённым ключом. WinSCP проверен на локальном SSH-fixture с разблокированным через Kageant ключом: это проверка аутентификации, не передачи SFTP в WinSCP. Нативные проверки встроенных передач файлов учитываются отдельно.

Linux-бинарники из `90db4a3` проверены на Ubuntu, включая restart с паролем и защищённым ключом. После удаления документации из AppImage/AppDir проведено сравнение всех оставшихся runtime-файлов с нативно проверенным комплектом и новый запуск AppImage. Исполняемые файлы, зависимости и ресурсы не изменились; GUI/SSH не запускались повторно ради упаковки. Отчёт: `dist/linux/minimal-package-check.json`.

Успешные незатронутые проверки сохраняют исходное происхождение. Контрольные точки пишутся после каждого сценария; сбой следующего не инвалидирует предыдущие. Отчёты: `dist/local-build.json`, `dist/local-tests.json`, `dist/linux/native-acceptance.json`, `dist/release-build.json`. После публикации контрольные суммы повторно скачанных пяти пакетов фиксируются в `dist/0.85-11-published-verification.json`. macOS 0.85-11 ожидает нативной подготовки отдельным Mac-чатом.
