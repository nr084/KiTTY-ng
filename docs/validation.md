# Область проверки 0.85-5

[Документация](README.md) · [Сборка](build.md) · [Следующие проверки](planned.md)

Все бинарные файлы и пакеты собраны **локально на Windows** компилятором Clang/LLD 23.1.3. Linux-виртуальная машина используется для целевых библиотек и нативных проверок.

| Проверка | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Архитектуры | x64, x86, ARM64 | Universal 2: ARM64 + Intel, все шесть файлов | x86_64, glibc 2.35 |
| Пакет | PE-архитектура и версия всех EXE, три ZIP | ad-hoc seals, ресурсы, права запуска, DMG round-trip | AppImage и AppDir, лицензии библиотек, FUSE/распаковка |
| Нативная проверка | Автоматические suites x64/x86: профили, языки, SSH, ключи, утилиты, SCP/SFTP и автоматизация | Предыдущая сборка подтверждена пользователем на M3; новый AppKit smoke-test собран, но на Windows не выполняется | Ubuntu 26.04/Xfce/X11: SSH, пароль/ключ/агент, профили, RU/EN, keygen, upload/download/drop, MC Shift+стрелки, переподключение; GUI от обычного пользователя |
| Новые действия | WinSCP: меню/Shift+F3, Unicode-путь, переменные окружения, поиск, недоступный путь и отклонение BAT | Перевод placeholder комментария, введённый текст сохраняется | Текстовый shortcut, блокировка ввода и окно команды проверены через SSH PTY; Ctrl-click через изолированный URI handler; GUI агента add/list/remove-one |
| Снимки | Новые снимки нативных окон с синтетическими данными | Сохранены прежние RU/EN главного окна и KiTTYgen | Новые снимки нативного GTK-интерфейса |

ARM64 Windows ранее подтверждён пользователем; обновлённые бинарники отдельно проверены по структуре PE. Linux Wayland, ARM64 и другие дистрибутивы, macOS Intel/macOS 13, SSH CA и Kerberos/GSSAPI с реальными учётными данными не заявлены как проверенные.

Windows не подписан Authenticode; macOS использует ad-hoc подпись, без Apple notarization. Сохранённый пароль KiTTY — совместимый обратимый формат, а не защищённое хранилище.
