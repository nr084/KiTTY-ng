# Область проверки 0.85-5

[Документация](README.md) · [Сборка](build.md) · [Следующие проверки](planned.md)

Исходный выпуск собирался локально на Windows. Mac-пакет 0.85-5 обновлён нативной сборкой **на Mac** компилятором LLVM 23.1.3; отчёты находятся в `dist/macos-native`. Версия и исходный тег сохранены, Windows/Linux-вложения не изменены. Linux-виртуальная машина используется для целевых библиотек и нативных проверок. [Подробный отчёт macOS](macos-native-validation.md).

| Проверка | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Архитектуры | x64, x86, ARM64 | Universal 2: ARM64 + Intel, все шесть файлов | x86_64, glibc 2.35 |
| Пакет | PE-архитектура и версия всех EXE, три ZIP | ad-hoc seals, ресурсы, права запуска, DMG round-trip | AppImage и AppDir, лицензии библиотек, FUSE/распаковка |
| Нативная проверка | Автоматические suites x64/x86: профили, языки, SSH, ключи, утилиты, SCP/SFTP и автоматизация | Нативные unit/AppKit/CLI tests ARM64 и x86_64 через Rosetta; loopback SSH/password/key/agent, SCP/SFTP, Unicode и рекурсивные передачи; реальные OpenSSH host/user certificates и отказ неверной области CA; GUI браузера, редактора, KiTTYgen и SSH-терминала | Ubuntu 26.04/Xfce/X11: SSH, пароль/ключ/агент, профили, RU/EN, keygen, upload/download/drop, MC Shift+стрелки, переподключение; GUI от обычного пользователя |
| Новые действия | WinSCP: меню/Shift+F3, Unicode-путь, переменные окружения, поиск, недоступный путь и отклонение BAT | Перевод placeholder комментария, введённый текст сохраняется | Текстовый shortcut, блокировка ввода и окно команды проверены через SSH PTY; Ctrl-click через изолированный URI handler; GUI агента add/list/remove-one |
| Снимки | Новые снимки нативных окон с синтетическими данными | Новые RU/EN главного окна и KiTTYgen на этом Mac, синтетические данные | Новые снимки нативного GTK-интерфейса |

ARM64 Windows ранее подтверждён пользователем; обновлённые бинарники отдельно проверены по структуре PE. Linux Wayland, ARM64 и другие дистрибутивы, физический Mac Intel/macOS 13, Kerberos/GSSAPI с действующими credentials не заявлены как проверенные.

Windows не подписан Authenticode; macOS использует ad-hoc подпись, без Apple notarization. Сохранённый пароль KiTTY — совместимый обратимый формат, а не защищённое хранилище.
