# Темы Windows

В **Окно → Оформление → Тема интерфейса** доступны «Как в Windows», «Светлая» и «Тёмная». Выбор применяется сразу и сохраняется отдельно от профилей. Открытые окна клиента и GUI-утилит получают уведомление об изменении. Автоматический режим следует системной теме приложений; высокая контрастность Windows имеет приоритет.

В портативном режиме настройка хранится в `kitty.ini`, секция `[KiTTY]`, параметр `UITheme`: `0` — автоматически (по умолчанию), `1` — светлая, `2` — тёмная. При обычной установке это DWORD `UITheme` в `HKCU\Software\KiTTY-NG`. Пользовательские цвета терминала сохраняются.

KiTTYgen и Kageant используют тот же выбор. Консольные Klink, Kscp и Ksftp используют оформление терминала. В Linux GUI-утилиты наследуют системную тему GTK.
