# Перенос расширений KiTTY

Базовый код заменён официальными исходниками PuTTY 0.85. Предыдущий KiTTY основан на PuTTY 0.76 и содержит также дерево `0.76b_My_PuTTY` с изменённой структурой каталогов. Механическое наложение патчей этих деревьев на 0.85 ненадёжно: изменились конфигурация, представление сеансов, SSH и организация исходников. Расширения адаптируются к современным интерфейсам PuTTY по отдельности.

История KiTTY сохранена до коммита `75fa2abcd220c17249ff7252f8d5224137001f2d`; локальная ветка `upstream-kitty` указывает на него. Коммит `d5c8fc06d387c58e5434818fbf8b6c3ed4e9fb23` фиксирует замену рабочего дерева на PuTTY 0.85. Изменения после него можно сравнивать с чистой современной базой.

## Реализовано в тестовой версии

| Область | Реализация и проверка |
| --- | --- |
| Современные протоколы и криптография | Код PuTTY 0.85; штатная криптографическая тестовая серия |
| Портативные сессии | Старые `Sessions`, `%XX`, `Ключ\значение\`, вложенные папки, расширения файлов; тест чтения, записи и сохранения неизвестных полей |
| Портативные ключи сервера | `SshHostKeys`, старые имена файлов и суффиксы; проверка чтения и записи |
| Пользовательские пути | Параметры `putty.conf`, `kitty.ini`, выбор каталога через `--portable-dir`; дочерние сеансы наследуют каталог |
| Сохранённый пароль | Совместимая реализация старого обратимого алгоритма на C для всех архитектур; 1996 сравнений с исходной библиотекой, 20 фиксированных векторов |
| Вход под root | Локальный SSH-сервер, GUI и Plink, password и keyboard-interactive, x64 и x86 |
| Папки и поиск сессий | Выбор каталога и фильтр; операции выполняются по исходному идентификатору сессии |
| Интерфейс | Русский/английский, каталог переводов и проверка строк/форматов, Unicode-элементы Windows |
| Прозрачность | Совместимое поле `TransparencyValue`, настройка окна |
| Системный трей | Команда меню, восстановление окна; при перезапуске Explorer скрытое окно становится доступным |
| Переподключение | Настраиваемая задержка после потери установленной SSH-сессии; отказ входа и обычный выход не повторяются |
| Архитектуры | Windows x64, x86 и ARM64; нативная проверка ARM64 ещё требуется |

## Требуют дальнейшего переноса

В старом дереве найдены отдельные расширения: фоновые изображения, Zmodem, интеграция FAR2L, RuTTY/скрипты, port knocking, пользовательские раскладки клавиш, дополнительные механизмы запуска и прокси. Эти расширения **не входят** в текущую тестовую версию. Их совместимость нельзя выводить из того, что неизвестные поля сессии сохраняются.

Также не реализовано чтение целиком зашифрованных профилей с мастер-паролем. Импорт реестра старого KiTTY не выполняется автоматически: основной сценарий совместимости этой версии — портативные каталоги.

Этот документ фиксирует текущий объём переноса. Полная миграция всех расширений KiTTY ещё не завершена.

Исходные переключатели `MOD_*` и файлы их использования перечислены в [машинном отчёте аудита](kitty-feature-audit.json). Его можно обновить командой `python tools/audit-kitty.py`: отчёт извлекает исходники из сохранённого коммита Git, исключая дубликат старого дерева `0.76_My_PuTTY`. Один переключатель не равен одному патчу; часть расширений не имеет отдельного `MOD_*`.
