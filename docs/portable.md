# Портативные профили и совместимость

[Документация](README.md) | [English](portable.en.md)

Сначала сделайте копию каталога старого клиента. Разместите kitty-ng в копии рядом с `kitty.ini`, `Sessions` и `SshHostKeys` либо укажите каталог явно:

```powershell
.\kitty-ng-x64.exe --portable-dir "D:\Terminal\KiTTY"
```

Поддерживаются старые файлы сессий `Ключ\значение\`, кодирование `%XX`, вложенные каталоги, расширения файлов из `kitty.ini` и пути из `putty.conf`. Неизвестные поля старого KiTTY сохраняются при перезаписи сессии. Окно сеансов открывает главную папку: подкаталоги показаны как `<имя>`, двойной щелчок открывает папку, `..` возвращает на уровень выше. «Быстрый поиск» ищет по названиям в текущей папке без учёта регистра.

Сохранённый пароль загружается из старого поля `Password` с учётом `cryptsalt`. В том числе поддерживается вход под `root`, обычная SSH-аутентификация паролем и запрос пароля через keyboard-interactive. Пароль хранится в совместимом обратимом формате KiTTY; это **не защищённое хранилище секретов**. Доступ к файлу сессии позволяет восстановить пароль. Не публикуйте реальные `Sessions`, `kitty.ini` и ключи.

Полностью зашифрованные файлы профилей с мастер-паролем не поддерживаются; перед переносом экспортируйте их старым KiTTY в обычный формат. Нераспознанные непустые профили не перезаписываются. Если старый пароль не удалось декодировать, исходное значение сохраняется; введите пароль вручную для замены.

В портативном режиме при сохранении сеанса SSH-ключ и отдельный SSH-сертификат внутри портативной папки записываются относительными путями, например `SSH-Keys\client.ppk`. При загрузке они разрешаются относительно портативной папки, а не рабочего каталога. Поэтому папку можно переносить вместе с ключами; клиент, Klink, Kscp и Ksftp продолжат использовать сохранённые ссылки. Внешние ключи сохраняются абсолютными путями. По умолчанию корень — каталог EXE; при `--portable-dir` или `KITTY_NG_PORTABLE_DIR` используется выбранный портативный каталог. Формат файлов KiTTY и его кодирование `%XX` сохраняются. KiTTYgen и Kageant не сохраняют ссылки на ключи в сеансах; их обычные операции открытия и сохранения файлов сохраняют стандартное поведение.

Кнопка «Обновить профили до последней версии» под «Удалить» обрабатывает все сохранённые портативные сеансы, включая вложенные папки. Она заменяет внутренние абсолютные пути к ключам и сертификатам относительными, не меняя остальные строки профилей, и показывает количество обновлений и ошибок. Уже относительные ссылки и внешние ключи остаются без изменений.

Для общего хранилища с Mac см. [руководство macOS](macos.md). Mac-поля шрифтов и геометрии окна хранятся отдельно; абсолютные Windows-пути автоматически не преобразуются. Seed-файлы разделены: `kitty-ng-win.rnd` и `kitty-ng-macos.rnd`.
