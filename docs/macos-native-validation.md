# Нативная проверка macOS — 13 октября 2026

[macOS](macos.md) · [Сборка](build.md) · [Область проверки](validation.md)

Mac-пакет существующего выпуска **0.85-5** пересобран на Mac без изменения номера и тега; Windows/Linux-пакеты сохранены. Предыдущий DMG, собранный на Windows, сохраняется отдельным архивным вложением релиза. macOS теперь собирается на Mac; сборка macOS на Windows отключена. Windows/Linux-пакеты и прежняя страница GitHub сохраняются в процедуре выпуска.

Среда: macOS 27.0.1 (26A434), Apple Silicon ARM64, системный SDK 27.0. Основная сборка — официальный LLVM 23.1.3, CMake 4.4.4, Ninja 1.13.2; точные строки версий, источник LLVM и SHA-256 архива записаны в `BUILD-INFO.json` и отчёте сборки. Предварительная диагностика выполнялась Apple Clang 21.0.0. Все шесть файлов Universal 2: основной клиент, Klink, Kscp, Ksftp, KiTTYgen, Kageant. x86_64 запускался через Rosetta, а не на физическом Intel Mac.

## Проверка живого интерфейса

Четыре снимка RU/EN браузера сеансов и KiTTYgen в `docs/screenshots` сняты с работающего AppKit-приложения на этом Mac; профили и ключ синтетические.

На ARM64 проверены браузер сеансов, поиск без учёта регистра, смена RU/EN, редактор и дерево всех параметров, сохранение Unicode-заметок, окно KiTTYgen и сохранность комментария при смене языка. SSH-терминал подключился к loopback-серверу с сохранённым паролем: проверены диалог host key, вывод кириллицы/emoji/рамок, вставка текста и получение серверного эха.

Передача из GUI через SFTP прошла побайтную сверку. В основной сборке LLVM отдельно проверена передача через SCP с приватным снимком конфигурации: имя файла с кириллицей, emoji и пробелом, каталог назначения с пробелами, кавычкой, `$()` и скобками. Эти символы остаются частью пути. Исправление ограничено Mac-помощником, вызываемым GUI; обычная shell-семантика CLI SCP не меняется.

Сервер подтвердил получение автокоманды и относительного UTF-8-скрипта после готовности SSH-канала. Искусственный обрыв TCP привёл к автоматическому переподключению с сохранённым паролем и повторной отправке скрипта/автокоманды. При явно включённом `EnableShortcuts` проверены Ctrl+F9: вставка и Return не доходят до сервера при защите ввода, а после снятия защиты доходят. Пользовательское сочетание Ctrl+Shift+K из `[Shortcuts]` отправило заданный текст. С отключённым `EnableShortcuts` F9 штатно передаётся в терминал.

Во время работы с диалогом выбора был ошибочно подтверждён пользовательский каталог. Передача шла на локальный синтетический сервер, была остановлена; временные копии удалены. Исходные файлы не изменялись. Этот эпизод не считается тестом на синтетических данных.

HTTP-прокси с ответом `407` и нулевым телом выявил ожидание лишнего байта после пустой строки. Разбор конца заголовков исправлен; повторная Basic-авторизация и SOCKS5 с паролем проходят на обоих срезах. Прокси принимают только loopback-соединение к заданному тестовому SSH-порту.

## Пакет и подпись

Проверены точный набор архитектур, отсутствие зависимостей вне системных библиотек, ad-hoc подписи и ресурсы bundle. Нативный `codesign` отверг изменённые страницы кода и изменённый ресурс. HFS+ DMG создан и проверен `hdiutil`, смонтирован только для чтения; содержимое приложения побайтно совпало с исходным bundle, права запуска и подпись сохранены. После проверки образ извлекается.

Артефакты находятся в `dist/macos-native`. Основные отчёты: `macos-build.json`, `macos-dmg.json`, `runtime-arm64.json`, `runtime-x86_64.json`, `keys-arm64.json`, `keys-x86_64.json`, `gui-acceptance.json`, `certificates.json`, `proxies-arm64.json`, `proxies-x86_64.json`, `gui-x86_64.json`; журналы — в `logs`. Результаты незатронутых успешных проверок используются повторно.

## Воспроизведение

```sh
python3 tools/local-build.py --platform macos
python3 test/macos_native_keys.py dist/macos-native/KiTTY-ng.app --arch arm64 --report dist/macos-native/keys-arm64.json
python3 test/macos_native_keys.py dist/macos-native/KiTTY-ng.app --arch x86_64 --report dist/macos-native/keys-x86_64.json

# Только для сетевых проверок; временную среду удалить после работы:
python3 -m venv build/macos-test-venv
build/macos-test-venv/bin/python -m pip install paramiko
build/macos-test-venv/bin/python test/macos_native_runtime.py dist/macos-native/KiTTY-ng.app --report dist/macos-native/runtime-arm64.json
build/macos-test-venv/bin/python test/macos_native_runtime.py dist/macos-native/KiTTY-ng.app --arch x86_64 --report dist/macos-native/runtime-x86_64.json
```

`--gui-fixture <путь.json>` поднимает изолированный сервер и запускает приложение с временными профилями до завершения клиента; `--gui-scp` выбирает регрессионный SCP-сценарий, `--gui-automation` — автокоманды, относительный скрипт, обрыв и переподключение, включённые сочетания. Сервер записывает принятые команды в JSON fixture. Профили удаляются при завершении fixture.

## Ограничения покрытия и замечания

Физический Intel Mac и macOS 13 не проверялись. Нет утверждения о проверке всех функций порта: отдельная среда нужна для Kerberos/GSSAPI с действующими credentials, аппаратного serial, прокси в реальной инфраструктуре и восстановления после настоящего сна Mac. Автоматизация, reconnect, повторная отправка скрипта/автокоманды и включённые сочетания проверены в GUI на ARM64 и отдельно в x86_64 через Rosetta.

В русском диалоге подтверждения host key заголовок и кнопки переведены, часть подробного текста остаётся английской. Подпись ad-hoc не является Developer ID/нотариальным заверением; Gatekeeper при загрузке из интернета и AppTranslocation здесь отдельно не проверялись.

Для итоговой сборки восстановлен Git checkout исходного репозитория. `BUILD-INFO.json` фиксирует коммит исходников Mac-пакета. Тег `v0.85-5` остаётся на исходном коммите общего выпуска; обновление только Mac-пакета не переносит тег и не меняет происхождение Windows/Linux.
