# Локальные исправления Windows — 12 октября 2026

Эти исправления подготовлены для 0.85-3. Windows EXE и утилиты упакованы в `dist/kitty-ng-0.85-3-{x64,x86,arm64}.zip`; выпуск дополняется macOS Universal DMG.

- **KiTTYgen и Kageant:** меню передавало старые внутренние имена `puttygen`/`pageant`, отсутствующие в разрешённом списке. Исправлены на `kittygen`/`kageant`; поиск рядом с клиентом и проверка архитектуры PE сохранены. Настоящий обработчик меню проверен с исполняемыми пробниками в пути с кириллицей и пробелами.
- **Журнал:** UTF-8 передавался ANSI listbox API и копировался как CF_TEXT. Теперь окно Unicode, строки добавляются/измеряются wide API, копирование использует CF_UNICODETEXT. Проверены кириллица/emoji и буфер для clipboard, без изменения пользовательского clipboard. Окно растягивается, имеет минимальный размер, отступы и центрированные кнопки.
- **Получить файл:** переводились дочерние элементы, но не caption диалога. Заголовок локализован отдельно; проверен настоящий диалог и отмена.
- **Сеансы:** вместо плоских путей — вложенные подменю, каталоги первыми, Unicode, буквальное `&`; ID сохраняют индекс оригинального списка. Проверены несколько уровней, совпадающие leaf-имена, обновление дерева и лимит меню.
- **Shift + стрелки:** оригинальный [KiTTY MOD_KEYMAPPING](https://github.com/cyd01/KiTTY/blob/master/0.76b_My_PuTTY/terminal/terminal.c) отправлял CSI с модификатором, тогда как стандартный режим PuTTY SHARROW_APPLICATION игнорирует Shift. При отсутствии настройки Windows теперь выбирает SHARROW_BITMAP; bitmap имеет приоритет над application cursor SS3. Для сохранённых старых профилей с `ShiftedArrowKeys=0` также передаётся Shift; поведение Ctrl без Shift (переключение app mode) сохраняется. Проверены 64 сочетания/режима форматтера и передача Shift+Up/Down через настоящий Windows frontend на локальный SSH-сервер. Реальное выделение файлов в MC на пользовательском сервере ещё требует проверки.
- **Seed:** новые имена по умолчанию `kitty-ng-win.rnd` для Windows и `kitty-ng-macos.rnd` для macOS разделяют записи платформ в синхронизируемой папке. Windows сохраняет явно настроенный `seedfile`/`RandSeedFile`; Mac использует отдельный `macseedfile` в putty.conf. Старые seed-файлы не удаляются. RNG продолжает использовать системную энтропию; существующие SSH-ключи и сеансы от переименования seed не зависят.

Сборка Clang 23.1.3: x64, x86, ARM64. Новые UI-проверки выполнены нативно x64/x86, меню/SSH/диалог — x64; ARM64 проверен компиляцией. Прежние неизменившиеся suites повторно не запускались. Результаты: `dist/windows-checks.json`, `dist/windows-arrow-test.json`.

Пользователь 12 октября 2026 года подтвердил хорошую работу ранее полученной Windows ARM64-сборки. Нативные сценарии сегодняшних новых изменений ARM64 отдельно ещё не проверены.

Вернулось меню значка клиента в трее: восстановление, информация о программе, выход с обычным подтверждением закрытия. Поддержаны оба языка.
