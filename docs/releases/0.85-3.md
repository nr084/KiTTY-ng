# KiTTY-NG 0.85-3

**macOS Portable + общие Windows-профили.** Приложение не требует установки: `KiTTY-NG.app` можно держать рядом с Windows EXE и использовать тот же каталог `Sessions`, ключи сервера и относительные ссылки на SSH-ключи. Настройки сохраняются снаружи `.app`; профили исходного портативного KiTTY также читаются.

Первый выпуск с нативным **macOS Universal**: одно приложение для Apple Silicon (ARM64) и Intel (x86_64). Базовая версия PuTTY — 0.85.

## Скачать

- Windows x64: `kitty-ng-0.85-3-x64.zip`.
- Windows x86: `kitty-ng-0.85-3-x86.zip`.
- Windows ARM64: `kitty-ng-0.85-3-arm64.zip`.
- macOS Universal: `kitty-ng-0.85-3-macos-universal.dmg`, macOS 13 и новее.

Windows-архивы включают клиент и пять утилит своей архитектуры. В DMG находятся `KiTTY-NG.app` с пятью встроенными Universal-утилитами и инструкции. Имена EXE не содержат номера версии; версия сохраняется внутри программ.

## macOS

Нативный терминал и русский/английский интерфейс, общий portable-каталог с Windows, папки и быстрый поиск сеансов, редактор и дублирование профилей, исправленное переключение языка и порт 22 для нового SSH-сеанса, KiTTYgen и Kageant. Перенесены автокоманды, скрипты, сочетания клавиш, переподключение и передача файлов через kscp с настройками действующего сеанса.

Перетаскивание загружает файлы без вопроса о каталоге: используется текущий известный путь, сохранённый удалённый каталог или `.`. Скачивание доступно в меню терминала. Рамки Midnight Commander рисуются по границам ячеек, Shift+стрелки передают модификатор и для старых профилей. Есть SSH CA, системный GSSAPI, дерево настроек, дополнительные шрифты и чтение старых имён CP1251; специальные сценарии CA/Kerberos требуют дальнейшей проверки.

Откройте DMG и перенесите `.app` в папку с профилями; не запускайте portable-клиент прямо из образа. Приложение имеет ad-hoc подпись, без Developer ID и нотариализации: при блокировке используйте «Настройки системы → Конфиденциальность и безопасность → Всё равно открыть». Полные инструкции: [русский](https://github.com/nr084/kitty-ng/blob/main/docs/macos.md) / [English](https://github.com/nr084/kitty-ng/blob/main/docs/macos.en.md).

## Windows

Исправлены запуск KiTTYgen/Kageant из меню, кодировка и копирование журнала, перевод окна получения файла и Shift+стрелки. Журнал растягивается, кнопки центрированы. Сохранённые сеансы представлены вложенными подменю; возвращено меню значка в трее.

Windows и Mac используют отдельные seed-файлы `kitty-ng-win.rnd` и `kitty-ng-macos.rnd`, чтобы не перезаписывать один файл в синхронизируемой папке. Исправлен пропуск первого пути kscp после `--`.

Сборки выполнены локально. Основные сценарии Mac и Windows ARM64 подтверждены пользователем; кросс-сборка не заменяет проверку каждой функции на целевой системе. Спасибо Simon Tatham и участникам PuTTY, Cyril Dupont и участникам KiTTY.
