# KiTTY-ng 0.85-4

**Windows, macOS Universal и Linux — единый портативный SSH-клиент на базе PuTTY 0.85.**

## Новое

- Первый Linux-выпуск: нативный GTK 3-интерфейс, AppImage x86_64 и архив AppDir.
- Общие портативные профили Windows/macOS/Linux: папки, поиск, создание, изменение и дублирование; относительные пути к ключам и сохранение неизвестных полей KiTTY.
- Linux: SCP/SFTP, перетаскивание файлов, получение файлов, KiTTYgen/Kageant, стартовые команды, скрипты и переподключение. Пользовательские сочетания, блокировка ввода и HTTP/HTTPS по Ctrl+щелчку; исправлена инициализация X11-агента, проверено удаление отдельного ключа.
- Новые Windows SSH-профили получают порт 22; macOS KiTTYgen переводит подсказку комментария при переключении языка, сохраняя введённые данные.
- Исправлено сохранение параметра «Поверх окон» в общем конфиге.
- Название интерфейса и документации унифицировано: **KiTTY-ng**. Служебные идентификаторы и формат существующих профилей сохранены.

## Выбор пакета

| Система | Пакет |
| --- | --- |
| Windows x64 / x86 / ARM64 | Отдельный ZIP каждой архитектуры |
| macOS 13+ · Apple Silicon / Intel | Universal 2 DMG: обе архитектуры клиента и всех утилит |
| Linux x86_64 | AppImage; резервный AppDir `tar.zst` |

**macOS поддерживает портативный режим и совместима с Windows-профилями.** Скопируйте `KiTTY-ng.app` рядом с общей папкой `Sessions`, `kitty.ini` и ключами. Данные хранятся снаружи bundle. Linux может использовать ту же папку через выбор каталога или `--portable-dir`.

## Проверка

Все сборки и пакеты созданы локально на Windows. Windows x64/x86 проверены нативно; ARM64 — компиляцией и структурой PE. Linux проверен в Ubuntu 26.04/Xfce/X11 от обычного пользователя: SSH, ключ/агент, RU/EN, профили, SFTP, GUI upload/download/drop, MC Shift+стрелки и переподключение. macOS: проверены Universal-срезы, ad-hoc seals и DMG round-trip; текущий AppKit runtime не выполнялся на Windows. Пользователь ранее подтвердил Mac M3 и Windows ARM64.

Linux Wayland/ARM64 и дополнительные дистрибутивы пока не проверены. Пакеты Windows без Authenticode; macOS с ad-hoc подписью, без Apple notarization. Старые Mac-скриншоты сохранены; Windows/Linux обновлены.
