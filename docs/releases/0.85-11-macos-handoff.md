# Mac: подготовить и добавить macOS 0.85-11

Продолжи работу в общей папке `SynologyDrive/Проекты/KiTTY-NG`. Прочитай AGENTS.md и этот документ. Windows/Linux выпускает Windows-чат, macOS собирается только на настоящем Mac. Номер **0.85-11** повторно не повышать.

Исходная ревизия Windows/Linux-правок: `daead7b` (точный коммит Windows указан в манифесте опубликованного выпуска; Linux имеет отдельное происхождение). Получи актуальный origin/main, сохрани чужие изменения. Общая версия обязательна, совпадение коммитов платформ не требуется.

## Адаптация

- Дублирование и явный перезапуск несохранённого SSH-подключения используют введённый логин, пароль либо парольную фразу ключа только из памяти исходного подключения. Используй общий механизм `kr_auth_connection` и `kr_auth_duplicate`, проверь соответствие identity. Не записывай runtime-секреты в профиль, argv, журнал или временный файл. OTP и произвольные запросы сервера не переиспользовать; после отказа — обычный запрос без второй автоматической попытки.
- Пункт «Перезапустить сеанс / Restart Session» сразу после дублирования, доступен после отключения. Набор текста в отключённом сеансе не перезапускает и не закрывает окно.
- Учти новые общие изменения агентской библиотеки: `pageant.c`, `stubs/pageant-random.c`, `stubs/pageant-keylist.c`, CMake. Проверь отсутствие конфликтующих символов и работоспособность Mac-помощников. Windows-интеграция WinSCP не переносится на Mac.
- Проверь нативный ввод RU/EN после переключения окон/вкладок, если вкладки поддерживаются текущим Mac-портом. Сохрани серый крестик и красное выделение при наведении; не заявляй поддержку отсутствующих функций.
- Используй названия Klink, Kscp, Ksftp, KiTTYgen, Kageant в пользовательском интерфейсе. Имена протоколов Pageant, формат PuTTY PPK, upstream copyrights сохраняются. Новые строки — только через общее языковое ядро EN/RU.
- Пакет минимальный: в DMG приложение, без отдельного Instructions, README, документации, скриншотов и декоративных изображений. Лицензии и встроенные ресурсы приложения/иконки сохранить. Windows-чат уже изменил упаковщик, но Mac-проверка ещё нужна.

## Сборка и проверка

Проверь последний официальный stable компилятора; если он обновился, обнови локальный toolchain перед сборкой. Сохрани реальное происхождение и точную версию. Собирай штатно:

```sh
python3 tools/local-build.py --platform macos
```

Приложение и пять помощников — Universal 2. Нативно проверь arm64 и x86_64 через Rosetta, подпись, монтирование и запуск DMG, комплектность лицензий и отсутствие документации в образе. Проверяй только затронутые сценарии и новые регрессии; успешные незатронутые результаты используй с исходным происхождением. Дополнительно проверь unsaved password/key duplicate/restart, единственную автоматическую попытку при неверном пароле, отсутствие сохранения секрета, портативные Windows-профили и RU/EN. Не выдавай проверки Windows/Linux за проверки Mac.

Обнови Mac-скриншоты с синтетическими профилями: главное окно и KiTTYgen RU/EN. Личные пути скрывай, пиксели интерфейса не перерисовывай. Обнови Mac-документацию; особо отметь портативность и совместимость Windows-профилей.

## Публикация

После успешной сборки самостоятельно добавь **только** `kitty-ng-0.85-11-macos-universal.dmg` в существующий выпуск `v0.85-11`, используя штатный `tools/update-macos-release.py` (сначала прочитай его аргументы и проверки). Не создавай второй выпуск, не перемещай тег, не заменяй Windows/Linux-вложения и независимый плагин. Сохрани реальные отдельные коммиты платформ и отчёты. После загрузки проверь SHA-256 DMG, обнови общий манифест/суммы и статус готовности Mac, README RU/EN: пять пакетов становятся шестью, ссылка DMG рабочая. Не объявляй успех до проверки загруженного пакета.

В GitHub сохраняются только свежий выпуск клиента и свежий независимый kitty-ng-fs. Не удаляй текущие Windows/Linux или плагин. После работы убери свои временные файлы, сохрани текущие пакеты, отчёты и установленные SDK/компиляторы. Сообщи URL релиза, Mac-коммит, SHA-256 и результаты нативных проверок.
