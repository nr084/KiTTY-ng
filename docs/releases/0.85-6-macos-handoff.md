# Передача сборки 0.85-6 на Mac

Промпт для отдельного чата на Mac:

> Продолжи подготовку KiTTY-ng 0.85-6 в этой же синхронизируемой папке проекта KiTTY-NG. Прочитай AGENTS.md. Windows x64/x86/ARM64 и Linux x86_64 собираются только в Windows-чате; здесь собирай исключительно macOS Universal 2. Версию не повышай: VERSION должен быть 0.85-6, bundle version — 0.85.6.
>
> Сначала проверь git status, текущий коммит и отчёты dist/local-build.json, build/linux-windows/linux-cross-build.json, dist/linux/native-acceptance.json. Не перезаписывай Windows/Linux-пакеты, их отчёты и контрольные суммы. Не выполняй reset/clean чужих изменений. Все готовые пакеты должны соответствовать проверенным исходникам.
>
> Для macOS подготовлены изменения: меню редактирования с Cmd+C/V/X/A через responder chain, включая --askpass; первая кнопка «Быстрое подключение» в браузере; редактор запускает временный Conf без имени/записи профиля. Реализация: macos/bootstrap.m, language.m/.h, editor.m/.h, client.m/.h, translations.h, selftest-ui.m. На Windows Mac-код не компилировался и не запускался — полноценно проверь его здесь и исправь обнаруженные ошибки.
>
> Выполни нативную сборку: `python3 tools/local-build.py --platform macos --output dist/macos-native`. Используй актуальный стабильный компилятор; сохраняй установленные инструменты. Проверь arm64 и x86_64 (через Rosetta на Apple Silicon), все Universal-помощники, подписи и монтирование итогового DMG. Используй существующие test/macos_native_*.py и smoke/self-test UI; не выдавай прежние результаты 0.85-5 за проверки 0.85-6.
>
> Обязательно проверь реальные Cmd+C/V/X/A в поиске, имени профиля, хосте, пользователе, путях ключа, комментарии KiTTYgen, прокси и SSH-диалогах. В паролях проверь вставку, сохраняя стандартные ограничения secure text fields. Терминальные сочетания и передача клавиш удалённому приложению должны продолжать работать. Проверь переключение RU/EN без потери данных.
>
> Проверь быстрое подключение к loopback SSH: порт 22 по умолчанию, ввод хоста/пользователя/ключа/пароля, отмена, неверный порт, успешное соединение, закрытие и дублирование окна. Сравни содержимое Sessions до и после: никаких новых профилей, изменений Default Settings или сохранённых паролей. Проверь, что семь кнопок полностью видны на минимальном размере окна в RU/EN; при необходимости поправь layout.
>
> Пересними два главных окна RU/EN с новой кнопкой и два окна KiTTYgen RU/EN с синтетическими данными. Только реальные пиксели, обрезка и непрозрачное скрытие личных путей через Pillow; без генеративной перерисовки. Сохрани в docs/screenshots/macos-session-en.png, macos-session-ru.png, macos-kittygen-en.png, macos-kittygen-ru.png. Обнови docs/macos-native-validation.md, docs/validation.md и заметки 0.85-6 по фактическим результатам. Особо сохрани описание портативного режима и совместимости профилей Windows/Linux/macOS.
>
> Итоговый пакет: dist/macos-native/kitty-ng-0.85-6-macos-universal.dmg, рядом отчёты macos-build.json, macos-dmg.json, gui-acceptance.json, runtime-arm64.json, runtime-x86_64.json и SHA256SUMS.txt. После правок зафиксируй итоговый коммит и повторно сформируй пакет с корректным происхождением. Не подделывай source_commit в отчётах.
>
> Публикация полного синхронного выпуска уже разрешена пользователем, но только после готовности всех шести пакетов одной версии и согласованного происхождения. Если Mac-правки/скриншоты изменили коммит относительно Windows/Linux, верни в Windows-чат точный коммит и список изменений для финальной пересборки/перепаковки. Не обходи проверки tools/release-build.py. Когда происхождение всех платформ согласовано: `python3 tools/release-build.py --assemble-only --macos-dir dist/macos-native`, затем `python3 tools/publish-release.py`. До публикации переведи ссылки README RU/EN на 0.85-6 и согласуй финальную упаковку документации. Предыдущие релизы и вложения сохранять. Удалить только свои временные файлы, сохранить итоговые пакеты и отчёты. В конце сообщи путь DMG, SHA-256, коммит и реальные результаты тестов.
