# KiTTY-ng 0.85-14

- Windows и Linux поддерживают отправку файлов, скопированных в файловом менеджере, через Ctrl+V в подключённом SSH-сеансе. В Linux используется список файлов в формате URI.
- В Windows указатель меняется на руку над HTTP(S)-ссылкой в терминале. Ctrl+щелчок открывает ссылку в браузере по умолчанию.
- Уменьшено окно подтверждения нового SSH-ключа в Windows. Ширина кнопок подстраивается под подписи.
- Лицензия PuTTY в пакетах называется LICENSE-PuTTY.txt.

Пакет macOS Universal 2 готовится отдельно.
