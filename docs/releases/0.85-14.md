# KiTTY-ng 0.85-14

- Windows и Linux поддерживают отправку файлов, скопированных в файловом менеджере, через Ctrl+V в подключённом SSH-сеансе. В Linux используется список файлов в формате URI.
- В Windows указатель меняется на руку над HTTP(S)-ссылкой в терминале. Ctrl+щелчок открывает ссылку в браузере по умолчанию.
- Уменьшено окно подтверждения нового SSH-ключа в Windows. Ширина кнопок подстраивается под подписи.
- Лицензия PuTTY в пакетах называется LICENSE-PuTTY.txt.

Сборка macOS Universal 2 готова для Apple Silicon и Intel.

- В активном SSH-сеансе ⌘V отправляет файлы, скопированные в Finder. Обычный текст вставляется в терминал.
- Указатель над HTTP(S)-ссылкой принимает форму руки. Control‑щелчок открывает ссылку, а обычное перетаскивание выделяет текст.
- Окно подтверждения SSH-ключа стало компактнее. Полный отпечаток доступен на русском и английском.
- Портативные сеансы macOS используют общий с Windows формат профилей. Папка данных находится вне приложения.
