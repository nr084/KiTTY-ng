# Нативная Mac-часть KiTTY-ng 0.85-8

Работать в общей синхронизируемой папке KiTTY-NG. Прочитать AGENTS.md. Windows-чат передаст точный согласованный коммит; версия уже 0.85-8, повторно не повышать. Не сбрасывать чужие изменения. Windows/Linux здесь не собирать, общий релиз не публиковать.

Изменения уже внесены: runtime-only авторизация дубликата через kittyng-auth.h и поля Conf NOT_SAVED; «Дублировать сеанс» в меню любой вкладки; серая кнопка закрытия с красным наведением; удалена строка Embedded HTML Help. Нативные вкладки 0.85-7 сохранены. Пароль и фраза ключа не должны сохраняться в профилях, аргументах запуска, журналах или временных файлах; серверные интерактивные ответы/OTP не повторяются.

1. Проверить последний официальный stable компилятора перед сборкой, обновить при необходимости. Использовать штатные скрипты и записать происхождение инструментария.
2. `python3 tools/local-build.py --platform macos` — собрать Universal 2 на настоящем Mac; выполнить штатную подготовку DMG и нативные проверки согласно docs/build.md. Эта команда сама создаёт и проверяет DMG; результаты не подменять.
3. Проверить ARM64 и x86_64 через Rosetta: обычный пароль, защищённый ключ, агент, быстрое подключение без профиля, дубликат неактивной вкладки, SessionTabs=0; отказ сохранённого в памяти пароля должен возвращать запрос. Закрытие исходного соединения не должно завершать копию. Проверить серый/красный hover, отсутствие анимации при дублировании в развёрнутое/полноэкранное окно, русский/английский интерфейс и отсутствие строки Help в About.
4. Проверить подпись приложения и пяти помощников, обе архитектуры, смонтированный DMG. Использовать и сохранить штатные JSON-отчёты в dist/macos-native. Старые отчёты не править вручную. При необходимых исправлениях сообщить новый коммит Windows-чату: тогда Windows/Linux также пересобираются из него.
5. Обновить Mac-скриншоты при необходимости. В документации подчеркнуть Portable и совместимость с Windows-профилями. Документацию после сборки не выдавать за коммит сборки.
6. Передать пользователю для Windows-чата: коммит, dist/macos-native/kitty-ng-0.85-8-macos-universal.dmg, SHA-256 и отчёты macos-build.json, macos-dmg.json, gui-acceptance.json, runtime-arm64.json, runtime-x86_64.json и остальные нативные результаты.

Windows-чат после приёма совпадающего Mac-пакета собирает общий манифест шести пакетов через tools/release-build.py --assemble-only --macos-dir dist/macos-native и публикует существующий черновик v0.85-8 через tools/publish-release.py. Затем обновляет RU/EN README и проверяет SHA-256 всех шести вложений и latest. Прежние релизы и независимый kitty-ng-fs сохраняются.
