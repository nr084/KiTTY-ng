# Обратная передача 0.85-6 из Mac-чата

Mac-пакет готовится в той же синхронизируемой папке KiTTY-NG. Версию **0.85-6** повторно не повышать. Исходная Windows/Linux-база — `b31bc612a6660acbc83d5ec2e8916fb7da835e28`.

Точный итоговый коммит, SHA-256 DMG, инструменты и состояние происхождения записываются в `dist/macos-native/macos-0.85-6-delivery.json`. Источник передаётся локальным Git bundle `dist/macos-source-0.85-6.bundle`; коммит также виден в Git Mac-копии. Пакет — `dist/macos-native/kitty-ng-0.85-6-macos-universal.dmg`.

## Изменения после b31bc61

- Исправлена локализация заголовка NSMenu: при RU→EN заголовок «Изменить» оставался русским, хотя пункты переводились. `macos/language.m` теперь переводит и сам NSMenu, в `macos/selftest-ui.m` добавлен regression test RU/EN.
- В loopback fixture добавлен режим `--gui-key-auth` для реального быстрого подключения с закрытым ключом.
- Пересняты четыре Mac-окна RU/EN с синтетическими профилями/ключом. Дополнены документация и заметки выпуска; README RU/EN подготовлены со ссылками 0.85-6 для общей публикации.
- Сборщик использует незатронутые результаты ядра/ключей, но повторяет изменённый AppKit smoke. `tools/macos-reuse-runtime.py` допускает повторное использование только результатов **той же версии** при строгом равенстве payload всех пяти помощников: игнорируются исключительно коммит, LC_UUID и подпись; исходные execution hashes сохраняются. При несовпадении выполняются новые проверки. Проверки `tools/release-build.py` не ослаблены.

## Действия Windows-чата

1. Сначала проверить `git status`, сохранить свои изменения. Не выполнять reset/clean. Если локальный Git Windows ещё на b31bc61, получить Mac-коммит без перезаписи файлов:

   ```powershell
   git fetch dist/macos-source-0.85-6.bundle main:refs/remotes/macos/main
   git merge --ff-only refs/remotes/macos/main
   ```

2. Сверить HEAD с `source_commit` в `macos-0.85-6-delivery.json`. Все пять имеющихся пакетов Windows/Linux и их отчёты первоначально относятся к b31bc61 и сохраняются неизменными до начала финальной пересборки. Не заменять source_commit вручную.
3. Из **этого же итогового коммита** пересобрать/перепаковать Windows/Linux с актуальным стабильным компилятором. Не запускать macOS на Windows:

   ```powershell
   python tools/local-build.py
   python tools/local-build.py --platform linux
   python tools/linux-package-windows.py
   ```

   Сохранить незатронутые успешные проверки согласно механизму зависимостей; нативная Linux-проверка должна соответствовать реально поставляемым бинарникам. Проверить версии всех EXE и архивов, README/документацию, `dist/local-build.json`, `build/linux-windows/linux-cross-build.json`, `dist/linux/linux-package.json`, `dist/linux/native-acceptance.json`.
4. Не менять отслеживаемые исходники или документы после согласования коммита. Если правки всё же нужны — передать новый коммит обратно Mac-чату для корректной переупаковки Mac, сохраняя 0.85-6. Встроенные коммиты и отчёты не подделывать.
5. После синхронизации финальных артефактов проверить одинаковую версию и происхождение всех шести пакетов. Сборку общего комплекта выполнить на Mac, где доступен настоящий bundle/помощники и нативные отчёты:

   ```sh
   python3 tools/release-build.py --assemble-only --macos-dir dist/macos-native
   python3 tools/publish-release.py
   ```

   Публикация разрешена исходной передачей только при успешном согласовании происхождения. До этого не создавать тег/черновик и не объявлять общий выпуск готовым. Предыдущие GitHub-релизы и вложения сохранять.

## Проверки Mac и очистка

Подробные фактические результаты — `gui-acceptance.json`, `runtime-arm64.json`, `runtime-x86_64.json`, `macos-build.json`, `macos-dmg.json` и [нативный отчёт](../macos-native-validation.md). x86_64 — Rosetta, физический Intel/macOS 13 не проверялись. Подпись ad-hoc без notarization. Только временные Mac-зависимости и промежуточные каталоги удаляются; компиляторы/SDK, конечный DMG и успешные отчёты сохраняются.
