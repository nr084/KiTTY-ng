# KiTTY-ng 0.85-11

## Windows и Linux

- Исправлен непостоянный ввод русского в Windows после смены вкладок и возврата из другого окна. Раскладка активной вкладки синхронизируется с окном вкладок; добавлен значок для Alt+Tab.
- В меню **Перезапустить сеанс / Restart Session** расположен сразу после дублирования и доступен после отключения. Обычный ввод не запускает новое подключение; в Linux он больше не закрывает отключённый сеанс.
- Несохранённые подключения поддерживают дублирование и перезапуск с ранее введённым логином, паролем или парольной фразой ключа. Данные повторного входа остаются только в памяти, привязаны к исходному подключению и не сохраняются в профиль. Одноразовые коды и запросы удалённого сервера не кэшируются; отказ пароля не вызывает повторных автоматических попыток.
- В Windows запуск WinSCP может использовать уже открытый защищённый ключ через Kageant. Парольная фраза не передаётся в командной строке или временном файле. Для утилит передачи файлов используется временный снимок текущего подключения, включая введённый вручную логин.
- Исправлены остатки стандартной отрисовки в тёмной теме и рамка фокуса, пересекавшая подписи флажков и переключателей. Исправлена динамическая подпись скорости COM-порта в русском интерфейсе.
- Названия сопутствующих утилит в интерфейсе, справке и описаниях файлов согласованы: **Klink, Kscp, Ksftp, KiTTYgen, Kageant**. Совместимость с агентом Pageant, форматом PPK и портативными настройками сохранена.

## macOS

macOS 0.85-11 готовится отдельно на настоящем Mac. До добавления Universal 2 DMG этот выпуск содержит только Windows/Linux и не является комплектом всех шести пакетов.

Портативный режим macOS и совместимость с Windows-профилями сохраняются: общий каталог `Sessions` и `kitty.ini` находится вне приложения. Mac-чат адаптирует изменения, выполняет нативные проверки и добавляет DMG в этот же выпуск без повторного повышения версии.

## Проверки

Сборки выполняются локально на Windows последним официальным стабильным LLVM-MinGW; Linux-пакеты проверяются нативно на Ubuntu. Происхождение и контрольные суммы каждой платформы сохраняются отдельно. Неизменившиеся успешные проверки используются повторно с исходными отчётами.
