# KiTTY-ng 0.85-1

Первый выпуск с новой схемой версий: `0.85` — база PuTTY, `1` — редакция KiTTY-ng. Выпуск публикуется без отметки `test`.

- Исправлено сохранение языка интерфейса. Рядом с раскрывающимся списком появилась кнопка «Применить»: она сохраняет язык для следующих запусков и обновляет интерфейс на текущей панели.
- В главном окне список сохранённых сеансов вмещает 14 строк, а блок «Закрывать окно при выходе» расположен внизу с тремя вариантами.
- Сохраняется совместимость с портативными настройками оригинального KiTTY, папками сеансов и сохранёнными паролями.
- Передача файлов через SFTP/SCP: отправка, скачивание и перетаскивание файлов и каталогов, Unicode-имена, настройки текущего SSH-сеанса, сохранённый пароль или ключ. Клиент вызывает kscp соответствующей архитектуры.

В выпуске три ZIP для Windows x64, x86 и ARM64; в каждом находятся клиент, klink, kscp, ksftp, kittygen и kageant своей архитектуры. В именах EXE нет версии, встроенные версии сохранены. Сборка выполнена локально стабильным Clang 23.1.3 / LLVM-MinGW 20261006.

На x64 и x86 проверены настройки и пароли KiTTY, SSH-аутентификация, SFTP/SCP, сохранённый SSH-ключ и сохранение языка после повторного запуска. Для ARM64 проверяются сборка, архитектура PE и версия; запуск на ARM64-устройстве ещё требуется. Успешные незатронутые тесты используются повторно.

Благодарности Simon Tatham и участникам PuTTY, а также Cyril Dupont (cyd01), автору KiTTY. Оригинальные тексты лицензий и уведомления об авторских правах сохранены.

Перенос расширений KiTTY продолжается. Zmodem, FAR2L, фоновые изображения, скрипты RuTTY, port knocking и остальные перечисленные в отчёте миграции расширения пока не входят в выпуск. Целиком зашифрованные профили с мастер-паролем не поддерживаются. EXE не подписаны Authenticode.

Тестовые релизы удаляются при этом переходе по прямому указанию пользователя. Следующие предыдущие релизы сохраняются.
