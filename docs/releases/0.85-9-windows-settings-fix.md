# Исправление настроек Windows в 0.85-9

По разовому разрешению пользователя от 28 октября 2026 обновляются Windows-пакеты текущего выпуска без повышения версии и без обновления скриншотов документации. Linux, macOS и независимый kitty-ng-fs сохраняются.

После открытия UTF-8-терминала `init_ucs` создавал однобайтную обратную таблицу для UTF-8. Последующее преобразование Unicode в UTF-8 ошибочно использовало её: терялась кириллица, неверно рассчитывались границы строк и повреждалась компоновка окна «Изменение настроек». Для UTF-8 такая таблица больше не создаётся; используется штатное многобайтное преобразование Windows.

В общий каталог добавлены переводы `System clipboard` («Системный буфер обмена») и `Last selected text` («Последний выделенный текст»), макросы этих строк включены в аудит переводов.

Регрессионные проверки: Unicode и переносы до/после инициализации терминала и смены кодировки; реальные страницы активного SSH-сеанса «Сигнал», «Кодировка», «Выделение», «Копировать», «Цвета», «Обмен ключами», «Туннели», «Автоматизация», «Профили прокси» на русском и английском. На прежнем опубликованном EXE проверка воспроизводит дефект.

Исправление оформляется отдельным коммитом Windows-пакетов. Исторический тег выпуска не переносится; происхождение незатронутых пакетов не меняется.
