# KiTTY-ng 0.85-test-3

- В главном окне настройки блок «Закрывать окно при выходе» с тремя вариантами перенесён к нижнему краю панели «Сеанс».
- Освободившееся место отдано сохранённым сеансам: список показывает 14 строк вместо 7.

Проверена компоновка русского и английского интерфейсов, обновлены скриншоты в README. Логика загрузки, сохранения, поиска сеансов и закрытия окна не менялась. Результаты ранее пройденных незатронутых тестов использованы повторно.

Три архива выпуска содержат клиент и пять утилит соответствующей архитектуры: x64, x86 и ARM64. Все сборки выполнены локально стабильным LLVM-MinGW/Clang 23.1.3 на базе PuTTY 0.85. Запуск на устройстве ARM64 ещё требует проверки.

Сохраняются возможности предыдущего выпуска: портативные настройки KiTTY, русский/английский интерфейс, передача файлов через SFTP/SCP и перетаскивание, вход с сохранённым паролем или SSH-ключом.

Благодарности Simon Tatham и участникам PuTTY, а также Cyril Dupont (cyd01), автору KiTTY. Оригинальные лицензии сохранены. Перенос остальных расширений KiTTY продолжается; текущий состав описан в README и отчёте миграции.
