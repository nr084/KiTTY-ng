## Обновление macOS 0.85-7: нативные вкладки

Mac-пакет обновлён без повышения версии. «Дублировать сеанс» теперь открывает независимое подключение в новой вкладке текущего окна, включая быстрое подключение без сохранения профиля. При одном сеансе полоса скрыта.

- Вкладки переключаются щелчком, меняют порядок перетаскиванием и через меню «Переместить влево / вправо».
- Красный крестик и «Закрыть вкладку» завершают только выбранную вкладку без подтверждения. При закрытии всего окна действует WarnOnClose.
- Верхнее меню и клавиатура относятся к активному терминалу. Фокус проверяется после переключения, перетаскивания, закрытия вкладки и отмены закрытия окна.
- `[KiTTY] SessionTabs=0` возвращает дублирование в отдельные окна; по умолчанию вкладки включены.
- Нативная реализация AppKit, Universal 2. Портативный режим и общие Windows-профили сохранены.

Тег и Windows/Linux-вложения сохраняются. Предыдущий Mac DMG остаётся архивным вложением; стандартное имя относится к новому пакету.
