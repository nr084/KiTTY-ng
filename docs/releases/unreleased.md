# Неопубликованные изменения

- Исправлено сохранение языка интерфейса: обработчик списка теперь принимает правильное событие выбора.
- Рядом со списком языка добавлена кнопка «Применить». Выбор до нажатия не записывается; после нажатия язык сохраняется для следующих запусков и интерфейс обновляется на той же панели.
- Обновлены русский и английский README и скриншоты. Добавлена проверка сохранения языка между процессами в портативном режиме и изолированном реестре.

Релиз выпускается только по отдельной команде пользователя.
