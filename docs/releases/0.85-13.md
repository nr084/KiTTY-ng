# KiTTY-ng 0.85-13

- Windows переподключает отключённый сеанс по клавише. Если за 3 секунды подключение не восстановилось, можно повторить попытку.
- В Windows обновлена отрисовка при дублировании сеанса, перетаскивании вкладок и переходах между страницами настроек. Перетаскиваемая вкладка подсвечивается синим.
- Исправлено оформление флажков, стрелок подменю и списков порядка алгоритмов SSH в Windows.
- Заголовок окна доверенных УЦ серверов использует имя KiTTY-ng и общий каталог переводов.

macOS Universal DMG готовится отдельно.
