# Общий финальный коммит 0.85-7 после Mac-изменений

Продолжить в общей синхронизируемой папке KiTTY-NG. Версию не повышать. Исходная база — `c060ad2de6460f470686c16b3c636348da985db7`; итоговый коммит передаётся пользователю отдельно и фиксируется в `dist/macos-native/macos-0.85-7-delivery.json`. Git bundle — `dist/macos-source-0.85-7.bundle`.

Изменились только Mac-интерфейс, сценарий его проверки и документация: дублирование активного сеанса в отдельное окно, верхнее меню, исключение AutoFill, временные настройки без сохранения профиля. Mac-вкладки, Windows/Linux-реализация вкладок и kitty-ng-fs не менялись.

1. Прочитать AGENTS.md, проверить собственные незакоммиченные изменения. Не сбрасывать общую папку. Получить согласованный коммит из origin/main либо bundle и сверить рабочие файлы с ним.
2. На Windows проверить официальный последний stable LLVM-MinGW, сохранить точную версию/происхождение. Собрать три Windows-пакета и Linux, используя существующий механизм повторного использования незатронутых успешных проверок:

   ```powershell
   python tools/local-build.py
   python tools/local-build.py --platform linux
   python tools/linux-package-windows.py
   ```

3. Нативная Linux-проверка должна покрывать именно новые поставляемые бинарники. Сохранить Windows/Linux пакеты и отчёты в dist и dist/linux, а `build/linux-windows/linux-cross-build.json` — на прежнем месте. Не пересобирать и не заменять Mac DMG, не менять происхождение отчётов вручную.
4. После согласования не менять отслеживаемые исходники/документы. При необходимой правке передать новый коммит Mac-чату для корректной пересборки. Сообщить итоговые commit и SHA-256 Windows/Linux.
5. Windows-чат ведёт выпуск, принимает проверенный Mac-пакет и выполняет общую сборку манифеста и публикацию после проверки всех шести пакетов:

   ```sh
   python3 tools/release-build.py --assemble-only --macos-dir dist/macos-native
   python3 tools/publish-release.py
   ```

Черновик v0.85-7 уже существует. Не использовать `--pending-macos` для окончательной публикации. Старые выпуски и независимый kitty-ng-fs сохранить. До согласованного происхождения всех пакетов выпуск не объявлять завершённым.
