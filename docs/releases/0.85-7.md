# KiTTY-ng 0.85-7

Вкладки сеансов в Windows/Linux и нативное меню сеанса macOS на базе PuTTY 0.85.

- «Дублировать сеанс» открывает независимое подключение в новой вкладке текущего окна. При одном сеансе полоса вкладок скрыта.
- Компактные вкладки с цветовым выделением активного сеанса и отдельной красной кнопкой закрытия.
- Изменение порядка перетаскиванием мышью; контекстное меню «Закрыть вкладку», «Переместить влево», «Переместить вправо».
- Закрытие отдельной вкладки без подтверждения; при закрытии всего окна настройка подтверждения сохраняется.
- `SessionTabs=0` в секции `[KiTTY]` файла `kitty.ini` возвращает дублирование в отдельное окно. По умолчанию вкладки включены.
- Linux собирается на Windows актуальным стабильным LLVM-MinGW, как и Windows-пакеты. Текущий компилятор — LLVM-MinGW 20261020 / Clang 23.1.4.

- macOS: «Дублировать сеанс» в контекстном и верхнем меню открывает независимое окно. Копии быстрых подключений остаются временными, без записи профиля и пароля в Sessions.
- macOS: верхнее меню «Сеанс» содержит команды активного терминала; AutoFill удалён из обоих меню терминала. Настройки временного подключения открываются с его текущими параметрами.
- macOS Portable: приложение и Windows EXE используют общий каталог профилей; данные и ключи хранятся снаружи подписанного `.app`. Все помощники Universal 2. Компилятор — официальный стабильный LLVM 23.1.4.

## Опубликованный выпуск

Выпуск опубликован с шестью пакетами: Windows x64/x86/ARM64, Linux x86_64 AppImage/AppDir и macOS Universal 2 DMG. Windows и Linux собраны локально на Windows; поставляемые Linux-бинарники проверены на Ubuntu. Mac-пакет собран и проверен на настоящем Mac: ARM64 нативно, x86_64 через Rosetta. Вкладки macOS отложены.

Коммит сборки всех пакетов: `336110e5d5750ea2dc93da4f510900cbd0009030`. Обновление документации после публикации не меняет исходники пакетов и релизный тег.

[Скачать KiTTY-ng 0.85-7](https://github.com/nr084/KiTTY-ng/releases/tag/v0.85-7).

Плагин kitty-ng-fs не изменяется и сохраняет собственный цикл выпуска.

## Исправление Windows от 27 октября 2026

Windows-пакеты 0.85-7 обновлены без изменения номера версии: исправлена потеря клавиатурного ввода и системный звуковой сигнал после переключения вкладок. Ввод проверяется через обычную очередь Windows, включая переключение, перетаскивание, закрытие вкладки и отмену закрытия окна. macOS и Linux не изменены; релизный тег сохранён на исходном коммите общего выпуска. Отдельный коммит исправления Windows и актуальные SHA-256 указаны на странице выпуска.
