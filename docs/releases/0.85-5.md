# KiTTY-ng 0.85-5

**WinSCP возвращается в Windows-меню. Общий выпуск Windows, macOS Universal и Linux на базе PuTTY 0.85.**

## Новое

- Windows: пункт **Запустить WinSCP** в меню окна терминала и **Shift+F3** при включённых сочетаниях KiTTY.
- Путь к установленному WinSCP читается из `[KiTTY] WinSCPPath` в `kitty.ini`. Поддерживаются относительный путь от портативного корня, переменные окружения, кириллица и пробелы. Без заданного пути проверяются установочные каталоги и WinSCP.exe рядом с портативными данными.
- В WinSCP передаются адрес, порт, пользователь, SFTP/SCP, удалённый каталог и SSH-ключ текущего сеанса. Поддерживаются SFTPConnect, WinSCPOptions и WinSCPRawSettings; два последних параметра доступны в Windows-настройках передачи файлов.
- Исправлена потеря кириллицы при чтении INI после инициализации терминала Windows.
- Недоступный явно заданный путь сохраняется; пользователь получает сообщение. Сохранённые пароли не экспортируются автоматически, полная команда не записывается в журнал. BAT-обёртки не запускаются; требуется WinSCP.exe.

WinSCP устанавливается отдельно и не входит в архивы. Встроенные SCP/SFTP и перетаскивание файлов работают независимо от WinSCP. Для macOS и Linux меню WinSCP не добавляется.

## Пакеты и совместимость

| Платформа | Пакет |
| --- | --- |
| Windows x64 / x86 / ARM64 | ZIP своей архитектуры |
| macOS 13+ · Intel / Apple Silicon | Universal 2 DMG |
| Linux x86_64 | AppImage и AppDir tar.zst |

Все платформы и утилиты имеют версию **0.85-5**. Сохраняется общий портативный формат KiTTY: **macOS и Linux совместимы с Windows-профилями**, относительными путями к SSH-ключам и общей папкой Sessions. Данные macOS хранятся снаружи приложения.

## Проверка

Исходный общий комплект собран локально на Windows; позднее Mac-пакет обновлён нативной сборкой на Mac (см. ниже). Windows x64/x86 — нативные проверки; ARM64 — сборка и структура PE. Интеграция WinSCP проверена через обработчик меню и Shift+F3 с отдельным синтетическим SSH-сеансом и исполняемым пробником: Unicode-путь, точные аргументы, поиск и сохранение недоступного пути. Linux — проверка поставляемого пакета в Ubuntu 26.04/X11. Исходный macOS-пакет проверялся по Universal-срезам, ad-hoc подписям и DMG round-trip; его запуск тогда не выполнялся. Ранее пользователь подтвердил Mac M3 и Windows ARM64.

## Обновление Mac-пакета — 13 октября 2026

- Universal 2 теперь собирается, подписывается и упаковывается локально на Mac через `python3 tools/local-build.py --platform macos`; сборка Mac-приложения на Windows отключена. Все шесть исполняемых файлов содержат arm64 и x86_64, минимальная версия системы — macOS 13.
- Исправлено зависание HTTP-прокси при ответе CONNECT/407 с пустым телом: конец заголовков распознаётся без ожидания лишнего байта. Проверяются HTTP Basic и SOCKS5 с синтетическими учётными данными на loopback. Исправление включено в обновлённый Mac-пакет; прежние Windows/Linux-вложения не пересобирались.
- Исправлено экранирование удалённых SCP-путей при передаче из Mac GUI: пробелы, кириллица, кавычки и символы оболочки остаются частью имени.
- Пройдены нативные unit/AppKit/CLI проверки arm64 и x86_64 через Rosetta, SSH с паролем/ключом/агентом, SCP/SFTP с двоичными данными и Unicode, KiTTYgen/OpenSSH, реальные SSH-сертификаты сервера и пользователя с проверкой области CA. В живом GUI проверены терминал, передача файлов, скрипты, автокоманды, переподключение и сочетания; снимки RU/EN обновлены.
- Проверены подписи, отклонение повреждённого кода и ресурсов, побайтное совпадение приложения после монтирования DMG. LLVM 23.1.3, CMake 4.4.4, Ninja 1.13.2 и точное происхождение сборки записаны в `BUILD-INFO.json`.

Версия и тег `v0.85-5` сохранены. Windows/Linux-вложения не изменены. Основной DMG — нативная сборка на Mac; архивный DMG прежней Windows-сборки удалён по прямому указанию пользователя. Физический Intel Mac, macOS 13, действующий Kerberos и аппаратный serial отдельно не проверялись; подпись ad-hoc без нотариального заверения Apple. [Подробный отчёт](https://github.com/nr084/KiTTY-ng/blob/main/docs/macos-native-validation.md).
