# KiTTY-ng 0.85-6

Синхронный выпуск Windows, Linux и macOS на базе PuTTY 0.85.

- Linux и macOS: первая кнопка «Быстрое подключение» открывает настройки соединения без запроса имени и сохранения профиля. По умолчанию SSH, порт 22.
- macOS: стандартные команды редактирования Cmd+C/V/X/A в полях настроек и диалогах ввода.
- Общий сетевой код: исправлено ожидание лишнего байта после пустой строки HTTP-прокси.
- macOS: безопасная передача путей SCP с пробелами из графического интерфейса.

Windows (x64, x86, ARM64) и Linux (x86_64 AppImage/AppDir) собираются локально на Windows. Universal 2 DMG собирается и проверяется отдельно на Mac из тех же исходников. Все шесть пакетов собраны из согласованного коммита `b95f861c7425b1d8c493c6bce9ba492d3a87161a`.

- macOS: заголовок меню редактирования корректно переключается между RU/EN вместе с его пунктами.

## Проверки macOS

Universal 2 собран локально на Mac. Проверены arm64 и x86_64 через Rosetta, нативные AppKit/CLI/unit suites, ключи и SSH/SCP/SFTP; новый GUI проверен на синтетических данных без сохранения быстрого соединения. Снимки главного окна и KiTTYgen RU/EN обновлены. Подробности и ограничения — [отчёт Mac](../macos-native-validation.md). Windows/Linux-пакеты прошли проверки и опубликованы вместе с Mac DMG. Предыдущие выпуски сохранены.
