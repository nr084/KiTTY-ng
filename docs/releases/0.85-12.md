# KiTTY-ng 0.85-12

В Windows проверка обновлений доступна в окне «О программе». Если на GitHub найден более новый выпуск, синяя ссылка открывает страницу скачивания. Автоматическая проверка выполняется в фоне не чаще раза за 24 часа для учётной записи Windows. Уведомление предлагает открыть страницу выпуска или закрыть его.

При дублировании сеанса окно вкладок обновляет геометрию видимого терминала без лишней перерисовки скрытых вкладок. При открытии подменю и возврате фокуса тема не применяется заново ко всему окну. При смене страницы настроек она применяется к новым элементам до их показа. В свойствах Windows и выборе приложения отображаются названия KiTTYgen, Kageant, Klink, Kscp и Ksftp.

В выпуск также вошли ручной перезапуск активного сеанса, исправления меню в трее, отрисовки тёмных подменю и рамки терминала после применения настроек. Поле имени сохранённого сеанса показывает путь относительно выбранной папки.

Если в поле сервера вставить HTTP- или HTTPS-адрес, KiTTY-ng использует только имя хоста или IP. Протокол и порт берутся из настроек сеанса.

**macOS Universal 2 готова.** [Скачать DMG](https://github.com/nr084/KiTTY-ng/releases/download/v0.85-12/kitty-ng-0.85-12-macos-universal.dmg).

В AppKit ручная проверка обновлений доступна в окне «О программе». Автоматическая проверка выполняется в фоне не чаще раза в сутки. При дублировании сохраняется окно, а геометрия терминала меняется только у активной вкладки. Из HTTP(S)-адреса берётся только хост или IP. Протокол, порт и имя пользователя берутся из настроек сеанса.

Портативный режим macOS совместим с Windows-профилями KiTTY-ng. Сеансы, ключи и настройки хранятся вне приложения. Приложение и пять помощников проверены из смонтированного DMG на ARM64 и через Rosetta. Mac-сборка сделана из `fa3b4f52183ee783771245073cc853bd1be9755e` официальным LLVM 23.1.5.
