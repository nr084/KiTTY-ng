# KiTTY-ng 0.85-12

В Windows проверка обновлений доступна в окне «О программе». Если на GitHub найден более новый выпуск, синяя ссылка открывает страницу скачивания. Автоматическая проверка выполняется в фоне не чаще раза за 24 часа для учётной записи Windows. Уведомление предлагает открыть страницу выпуска или закрыть его.

При дублировании сеанса окно вкладок обновляет геометрию видимого терминала без лишней перерисовки скрытых вкладок. При открытии подменю и возврате фокуса тема не применяется заново ко всему окну. В свойствах Windows и выборе приложения отображаются названия KiTTYgen, Kageant, Klink, Kscp и Ksftp.

В выпуск также вошли ручной перезапуск активного сеанса, исправления меню в трее, отрисовки тёмных подменю и рамки терминала после применения настроек. Поле имени сохранённого сеанса показывает путь относительно выбранной папки.

macOS Universal DMG готовится отдельно.
