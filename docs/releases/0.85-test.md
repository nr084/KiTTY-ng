# KiTTY-RUS 0.85-test

Первая тестовая версия на базе PuTTY **0.85**. Числовая версия совпадает с базовой версией PuTTY.

- Русский и английский интерфейс с запоминанием выбора языка.
- Портативные каталоги и старый формат файлов сессий KiTTY, папки и поиск сеансов.
- Загрузка и сохранение паролей в совместимом формате KiTTY, в том числе для входа под root.
- Прозрачность окна, сворачивание в трей и переподключение после обрыва установленной SSH-сессии.
- Новый значок: два терминала, соединённые кабелем.
- Сборки для Windows x64, x86 и ARM64; в каждом архиве есть терминал, Plink, PSCP, PSFTP, PuTTYgen и Pageant.

Распакуйте архив и запустите `kitty-rus.exe`. Архив включает маркер портативного режима. Для перехода со старого KiTTY сначала сделайте копию каталога его настроек; описание совместимости и переключения языка — в README.

Проверены сборки x64 и x86, старые файлы настроек, совместимость алгоритма сохранённого пароля, реальный SSH-вход password/keyboard-interactive и восстановление соединения. Штатная криптографическая серия PuTTY: 90 тестов. Для ARM64 проверены сборка и архитектура PE; запуск на ARM64 пока не проверен.

Перенос всех расширений старого KiTTY ещё не завершён. Фоновые изображения, Zmodem, FAR2L, RuTTY, port knocking и другие дополнительные расширения пока отсутствуют; полный список находится в `docs/migration.md`. Целиком зашифрованные профили с мастер-паролем не поддерживаются. Сохранённый пароль использует обратимый формат KiTTY. Исполняемые файлы не подписаны Authenticode.

Следующая тестовая версия: **0.85-test-2**. Стабильный выпуск после завершения проверки: **0.85**.
