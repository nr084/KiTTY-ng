# macOS 0.85-10: адаптация, нативная сборка и публикация

Работай на настоящем Mac в общей папке `SynologyDrive/Проекты/KiTTY-NG`. Прочитай `AGENTS.md`, включая последнее уточнение о самостоятельной публикации Mac. Windows/Linux 0.85-10 уже опубликованы: https://github.com/nr084/KiTTY-ng/releases/tag/v0.85-10. Твоя задача — адаптировать новые функции для macOS, нативно собрать Universal 2/DMG, проверить, подготовить скриншоты и добавить DMG в этот же выпуск.

## База и ограничения

- Получи актуальный `origin/main`, сохрани чужие изменения. База новых функций и Windows-пакетов: `a75dbae2175276e300d96281296f71d4cec72727`. Linux-бинарники: `f017213a633cf28f246038e32549bbd4cef1b59c`.
- Версия уже **0.85-10**. Повторно не повышать. Совпадение коммитов платформ не требуется. Отчёты должны отражать реальные чистые коммиты и поставляемые бинарники; provenance и результаты тестов вручную не исправлять.
- Windows/Linux не пересобирать и не заменять. Релизный тег не переносить. Независимый `kitty-ng-fs 1.1.1` не изменять.

## Адаптировать на Mac

1. **Быстрые команды**: максимум 20 именованных команд, общих для всех сеансов. Настройка соответствует **Окно → Быстрые команды / Window → Quick commands**; сделай аккуратный нативный редактор со списком, названием, длинной однострочной командой, флажком Enter, кнопками добавления, сохранения и удаления. Записи не должны попадать в файлы профилей. Сохранение и удаление применяются сразу; поясни это в интерфейсе.
2. Подменю запуска **Быстрые команды / Quick commands** сразу после **Специальной команды / Special Commands** в контекстном меню терминала; согласуй верхнее меню Mac с активным сеансом. Выбранная команда передаётся активному удалённому сеансу буквально. При `cmdX_enter=yes` отправляется Enter, при `no` — только текст. Учитывать блокировку ввода и готовность подключения.
3. Переиспользуй `kittyng-quick-commands.h` и `utils/kittyng-quick-commands.c`. Общий формат — секция `[QuickCommands]` файла `kitty.ini` в портативном корне, вне `.app`: `cmd1_name`, `cmd1_instruction`, `cmd1_enter=yes/no`, номера 1–20. В Windows установленный режим использует реестр; Mac должен совместно читать портативный INI.
4. При первом запуске без этого раздела создать один пример: `Update Ubuntu` / `Обновить Ubuntu`; команда `apt -y update && apt -y upgrade && apt -y autoremove`; Enter=yes. Создание записи ничего не выполняет. Существующие команды не перезаписывать. После удаления всех команд пустой раздел остаётся, и пример не возвращается. Смена языка не переводит и не переименовывает пользовательские записи.
5. В **О программе** рядом с версией показывать реальную дату сборки. Windows/Linux используют `kittyng-build-date.h`; на Mac сделай эквивалент для нативной сборки.
6. Использовать общее языковое ядро RU/EN (`locale/ru.json`, `locale/ru-contexts.json`, `tools/generate-translations.py`). Новые строки уже добавлены; дополняй общий каталог при необходимости. Не переводить пользовательские названия, команды, данные сервера и пути. Все поля должны поддерживать обычное копирование/вставку, кириллицу и Unicode.
7. Windows исправил ошибку однобайтной обратной таблицы для UTF-8, ломавшую переносы в настройках после SSH-входа. Mac-специфичные обходы этого Windows-дефекта не нужны; проверь своё отображение русских и английских строк. Сохрани уже работающие вкладки, серый/красный крестик при наведении, дублирование и однократную автоматическую попытку повторного использования пароля.

Примеры реализации: `quick-commands-config.h`, `windows/window.c`, `linux/quick-commands.h`; описание формата — `docs/quick-commands.md` и `docs/quick-commands.en.md`.

## Сборка и проверки

Проверь последний официальный stable-компилятор перед сборкой, обнови при необходимости и сохрани происхождение инструментов. Собирать только нативно на Mac:

```sh
python3 tools/local-build.py --platform macos
```

Используй штатные команды репозитория для DMG и нативной проверки. Приложение и пять помощников должны быть Universal 2 (arm64 + x86_64). Проверь ARM64 и x86_64 через Rosetta, подпись, монтирование DMG и запуск именно поставляемого приложения.

Нативно проверь быстрые команды: создание примера один раз; добавление/редактирование/удаление; все 20 записей; Enter=yes/no; ввод заблокирован; выбранная вкладка; пользовательские названия с кириллицей и `&`; сохранение других секций INI; совместимость UTF-16LE/BOM; отсутствие записи команд в профили; сохранение после перезапуска. Для отправки используй изолированный тестовый SSH-сервер и безопасные команды, а не реальное обновление Ubuntu. Сохранённые успешные незатронутые проверки повторно используй штатно.

Сними реальные RU/EN Mac-скриншоты с синтетическими данными, включая новые настройки быстрых команд и дату сборки. Обрезай программно без генеративной перерисовки. Сохрани подчёркнутые в документации **портативный режим macOS и совместимость с Windows-профилями**.

## Публикация Mac в существующий выпуск

Перед изменениями сохрани ID, имена, размеры и SHA-256 пяти вложений 0.85-10 и релизный тег. Windows/Linux проверены: 65 локальных наборов проверок и 11 нативных Linux-проверок. Их происхождение и бинарники не менять.

Обнови RU/EN README и `docs/releases/0.85-10.md`: убери ожидание macOS, добавь рабочую ссылку на `kitty-ng-0.85-10-macos-universal.dmg`, реальные результаты и изменения Mac. Зафиксируй и отправь исходники/документацию; собирай из чистого коммита. Последующий документационный коммит не выдавай за коммит сборки.

После готовности отчётов в `dist/macos-native` и синхронизации Windows/Linux-пакетов:

```sh
python3 tools/release-build.py --assemble-only --macos-dir dist/macos-native
python3 tools/publish-release.py --update-current
```

Манифест: версия 0.85-10, `status: success`, `release_scope: all`, ровно шесть пакетов. Не использовать `--pending-macos` или `--draft-only`. Если проверка не проходит — исправь причину, не обходи её. Скрипт должен сохранить неизменённые Windows/Linux-вложения по хешам и не переносить тег.

После публикации скачай DMG и проверь SHA-256, неизменность пяти Windows/Linux-вложений, шесть пакетов, статус latest и сохранность плагина. На GitHub остаются только последний клиент и последний плагин. Удали временные загрузки/промежуточные каталоги; сохрани актуальные пакеты, отчёты, компиляторы и SDK. Запиши `dist/macos-native/macos-0.85-10-delivery.json` с реальным коммитом, путём, SHA-256 и результатами. В ответе дай ссылку выпуска и результаты проверки.
