# KiTTY-ng 0.85-10

В подготовке: исправление компоновки и кириллицы настроек Windows после открытия SSH-сеанса, переводы вариантов буфера обмена, дата сборки рядом с версией, общие быстрые команды.

## Быстрые команды

- Контекстное меню: «Быстрые команды» после «Специальной команды».
- Редактор: «Окно → Быстрые команды», максимум 20 записей. Название, команда, флажок отправки Enter; добавить, сохранить, удалить.
- Общие настройки, вне профилей: Windows — HKCU\Software\KiTTY-NG\QuickCommands либо секция [QuickCommands] файла kitty.ini в портативном режиме. Linux — kitty.ini выбранного портативного каталога.
- Формат: cmd1_name, cmd1_instruction, cmd1_enter=yes/no, далее до cmd20. initialized=yes сохраняет намеренно пустой список.
- При первом запуске создаётся пример Update Ubuntu / Обновить Ubuntu с командой apt -y update && apt -y upgrade && apt -y autoremove и Enter=yes. Существующие записи не перезаписываются, после удаления последней записи пример не возвращается.
- Пользовательские названия и команды сохраняются буквально. Команда отправляется только после выбора пользователем и при доступном подключении; блокировка ввода учитывается.

Windows/Linux собираются локально на Windows. После их публикации — отдельный промпт для нативной macOS той же версии; Mac-чат адаптирует изменения, проверяет и добавляет DMG в этот выпуск. Портативный режим macOS и совместимость Windows-профилей сохраняются.
