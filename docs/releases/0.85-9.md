# KiTTY-ng 0.85-9

## Что изменилось

- Общее языковое ядро Windows, Linux и macOS: русский и английский встроены в приложение. Переводы собраны в общий каталог, который проверяется на пропуски и параметры форматирования.
- Расширен русский перевод журнала SSH, сообщений входа, аутентификации по ключу, предупреждений и подтверждений. Сообщения самого клиента используют выбранный язык; ответы сервера и пользовательские данные остаются без изменений.
- Исправлена кириллица в пути SSH-ключа в журнале Windows и при копировании журнала.
- Переведено подтверждение закрытия окна с несколькими вкладками. Закрытие отдельной вкладки по-прежнему не требует подтверждения.
- Убрана повторная анимация разворачивания при первом дублировании вручную максимизированного окна Windows.

- macOS: выбранная папка сеансов запоминается после перезапуска. Существующие сеансы в папке рядом с `.app` обнаруживаются автоматически без запроса; данные остаются вне bundle.
- macOS: исправлено сохранение настроек и положения окна при выходе: имя профиля остаётся корректным.
- macOS: в меню строки состояния добавлен пункт «Закрыть» с учётом подтверждения завершения сеансов.
- macOS: исправлено переключение русских/английских подписей без перевода названий языков и изменения редактируемых данных.

## Платформы и портативный режим

Windows: x64, x86 и ARM64. Linux: x86_64 AppImage и AppDir. Сборки Windows/Linux выполняются локально на Windows.

macOS Universal 2 (Apple Silicon и Intel) собирается и проверяется нативно на Mac; пакет включает обе архитектуры приложения и пяти помощников. Подпись ad-hoc, без Developer ID и нотариального заверения Apple.

**macOS поддерживает портативный режим и совместимые с Windows профили KiTTY.** Общую папку сеансов можно использовать между платформами; портативные настройки остаются вне подписанного приложения. Возможности и ограничения описаны в [документации macOS](../macos.md).

KiTTY-ng основан на PuTTY Simon Tatham и участников проекта и использует наследие KiTTY Cyril Dupont. Плагин kitty-ng-fs выпускается независимо и этим обновлением не изменяется.

## Проверка macOS

Mac-пакет собран из чистого коммита `4a6fd9a705f0fd6cf9f9f9c420e2b84ad3fa8996` официальным stable LLVM 23.1.4. Нативно проверены ARM64 и x86_64 через Rosetta: AppKit, RU/EN и редактирование, восемь сценариев пароля/ключа/агента/OTP, дубликаты, быстрые подключения без записи профиля, SSH/SCP/SFTP, прокси и сертификаты. Все шесть исполняемых файлов Universal 2; подпись и смонтированный DMG проверены. Физический Intel, macOS 13 и действующий Kerberos отдельно не проверялись. Документация и реальные Mac-скриншоты обновлены отдельным коммитом после сборки; он не заменяет происхождение бинарников.
