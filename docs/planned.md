# Проверки и дальнейшая работа

[Документация](README.md) · [Выпуск 0.85-5](releases/0.85-5.md)

Запланированные исправления SSH/22 в Windows и подсказки комментария ключа в macOS выполнены в 0.85-4. Linux получил нативный GUI, общий портативный формат, передачу файлов, автоматизацию, пользовательские сочетания, блокировку ввода и утилиты.

Остаются проверки на дополнительных системах: Linux Wayland и другие дистрибутивы, Linux ARM64, macOS Intel/macOS 13, Kerberos/GSSAPI с действующими credentials. Они не заявлены как выполненные. SSH CA с реальным сертификатом сервера и пользователя проверены локальным OpenSSH на ARM64 и x86_64 через Rosetta; см. [отчёт Mac](macos-native-validation.md). Windows ARM64 и macOS M3 ранее подтверждены пользователем; новые сборки проверяются отдельно по структуре и версии.

Отдельно отложенный по запросу пользователя копирайт сопутствующих утилит остаётся без изменений.

## Постоянные требования к каждому выпуску

- Перед каждой сборкой KiTTY-ng, включая пересборку текущей версии, проверять у официального поставщика последний stable компилятора для соответствующей платформы и использовать именно его; устаревший установленный компилятор сначала обновлять. Beta/RC/nightly вместо stable не использовать. Фиксировать точную версию и происхождение инструментов в отчёте. Windows и Linux собираются локально на Windows; macOS — только нативно в Mac-чате.
- После любого релиза удалять временные загрузки, промежуточные сборки, тестовые каталоги и ненужные локальные пакеты. Сохранять актуальные готовые пакеты, результаты проверок и установленные компиляторы/SDK. Опубликованные прежние релизы и их вложения не удалять.

## Следующий релиз — отложенные задачи

- **Windows и Linux: вкладки сеансов (TABs)** в следующем релизе KiTTY-ng. Уточнённое поведение по запросу пользователя от 27 октября 2026:
  - При обычном открытии одного сеанса панель вкладок скрыта: окно выглядит как сейчас.
  - Команда **«Дублировать сеанс»** создаёт независимое подключение с параметрами текущего сеанса в том же окне. Сверху появляется панель вкладок с исходным и новым сеансом; дальнейшие дубликаты добавляются туда же.
  - Возможность по умолчанию **включена**. Добавить документированный параметр в `kitty.ini`, позволяющий её отключить. При отсутствии параметра использовать включённое состояние; имя ключа — `[KiTTY] SessionTabs`.
  - При отключении через INI сохранить прежнее поведение: дублирование открывает отдельное окно без панели вкладок.
  - Проверить переключение и закрытие вкладок, независимость подключений, корректное завершение активных сеансов при закрытии окна и оба значения INI-параметра.
  - Реализуется и проверяется для 0.85-7 по отдельной команде пользователя на выпуск; текущее поведение описано в [руководстве вкладок](tabs.md).
- **macOS: нативные вкладки AppKit добавлены в обновление 0.85-7** по отдельной команде пользователя: дублирование в том же окне, независимые подключения, переключение, перетаскивание, контекстное перемещение/закрытие, SessionTabs=0.

- macOS: реализовано для подготовки 0.85-7 — независимое дублирование сеансов, включая временные соединения без записи профиля, через контекстное и верхнее меню; AutoFill исключён. Проверено на ARM64 и x86_64 через Rosetta.
- KiTTY-ng: убрать сообщение о вложенном HTML Help-файле. По запросу пользователя пока только зафиксировать задачу, не реализовывать. Удаление самой справки не требуется.

## Windows: запуск WinSCP из меню сеанса

В 0.85-5 возвращён пункт «Запустить WinSCP» в меню окна терминала, как в оригинальном KiTTY, рядом с запуском Kageant и KiTTYgen. Задача относится только к Windows; в меню macOS и Linux этот пункт не добавлять. Реализован запуск внешнего WinSCP с параметрами текущего сеанса и сообщением, если программа не найдена.
### Исследование оригинального KiTTY

Проверено по сохранённому исходному коммиту `75fa2abcd220c17249ff7252f8d5224137001f2d`: `kitty.c`, функции `SearchWinSCP` и `StartWinSCP`, а также `docs/pages/PscpIntegration.md`.

- Основной путь задавался в `kitty.ini`, раздел `[KiTTY]`, ключ `WinSCPPath`, например `WinSCPPath=C:\Program Files\WinSCP\WinSCP.exe`. Допускалась также `.BAT`-обёртка.
- Сначала проверялся заданный файл. Если он не существовал, старый код удалял параметр и искал по очереди `%ProgramFiles%\WinSCP\WinSCP.exe`, `%ProgramFiles%\WinSCP3\WinSCP3.exe`, `WinSCP.exe` в `InitialDirectory`, затем каталог из `[KiTTY] winscpdir`. Найденный путь записывался обратно в `WinSCPPath`.
- Пункт `Start WinSCP` был доступен при найденном пути; стандартное сочетание — `Shift+F3`, переопределение — `[Shortcuts] winscp`.
- Запуск использовал текущий сеанс: протокол `WinSCPProtocol`, пользователя, адрес, порт, удалённый каталог, SSH-ключ; поддерживал `SFTPConnect`, `WinSCPOptions`, `WinSCPRawSettings` и настройки прокси.

При реализации сохранить совместимость с `WinSCPPath` и исследовать корректное разрешение относительного пути от портативного корня. Отдельно проверить пути с пробелами/кириллицей, установку в Program Files и Program Files (x86), отсутствующий файл и BAT-обёртку. Не переносить механически старые ограничения ANSI/коротких имён, удаление пользовательского параметра при временной недоступности файла и запись полного запуска с паролем в журнал. Реализовано в 0.85-5 только для Windows: меню, Shift+F3, WinSCPPath, относительный путь, поиск установленного EXE, параметры текущего SSH-сеанса и поля WinSCPOptions/WinSCPRawSettings. BAT-обёртки проверяются и отклоняются с сообщением; пароль автоматически не экспортируется.

- Уточнение вкладок Windows/Linux для 0.85-7: по правой кнопке — «Закрыть вкладку», «Переместить влево», «Переместить вправо». На краях недоступное перемещение отключено. Перемещение сохраняет активный сеанс и подключение. Закрытие отдельной вкладки крестиком или через меню не запрашивает подтверждение даже при включённой настройке; закрытие всего окна учитывает настройку подтверждения.

- Оформление вкладок 0.85-7: компактная минималистичная полоса, активная вкладка выделена другим цветом; на каждой вкладке справа маленький красный круг с белым крестиком. Порядок меняется перетаскиванием мышью и через контекстное меню.
