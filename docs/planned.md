# Следующие задачи

[Документация](README.md) | [Изменения 0.85-3](releases/0.85-3.md)

Здесь перечислены открытые задачи после выпуска 0.85-3. Реализованные исправления описаны отдельно; версия повышается только по команде на релиз.

## Следующий выпуск

| Платформа | Задача | Критерий проверки |
| --- | --- | --- |
| Windows | В новом SSH-профиле показывать и сохранять порт 22 вместо 0 | Первый запуск, «Новый», смена протокола; заданные порты существующих сеансов сохраняются |
| macOS · KiTTYgen | Перевести placeholder `Key comment` | Смена RU/EN обновляет подсказку, введённый комментарий не меняется |

## Нативные сценарии, требующие подтверждения

- macOS: SSH CA, Kerberos/GSSAPI, зашифрованный ключ и агент при передаче файлов, длительная работа и сохранение общих профилей.
- macOS: Intel-часть Universal и нижняя граница macOS 13; результаты на M3 не заменяют эти проверки.
- Midnight Commander: Shift + стрелки на пользовательском сервере в Windows/macOS. Форматтер и передача через Windows frontend проверены; поведение конкретного MC требует отдельного подтверждения.
- macOS: нативный smoke-test смены языка и данных KiTTYgen. Получены RU/EN-снимки интерфейса; это визуальное подтверждение, а не выполнение всех автоматических сценариев.
- Синхронизация: записи seed разделены между Windows/macOS; параллельная работа нескольких Mac с одним seed остаётся отдельным сценарием.

## Уже вошло в 0.85-3

- Windows: Unicode-журнал, оформление и центрированные кнопки; запуск KiTTYgen/Kageant из меню; перевод окна скачивания; вложенные меню сеансов и меню трея.
- Windows/macOS: исправление Shift-последовательностей, отдельные seed-файлы платформ.
- macOS: новый профиль с SSH/22, исправление переключения языка и строки поиска, перевод локальных запросов парольной фразы, отправка без обязательного вопроса о каталоге, действия над профилями и непрерывные рамки терминала.

Подробности: [Windows](windows-fixes.md), [macOS](macos.md), [область проверки](validation.md).
