# Проверки и дальнейшая работа

[Документация](README.md) · [Выпуск 0.85-5](releases/0.85-5.md)

Запланированные исправления SSH/22 в Windows и подсказки комментария ключа в macOS выполнены в 0.85-4. Linux получил нативный GUI, общий портативный формат, передачу файлов, автоматизацию, пользовательские сочетания, блокировку ввода и утилиты.

Остаются проверки на дополнительных системах: Linux Wayland и другие дистрибутивы, Linux ARM64, macOS Intel/macOS 13, SSH CA и Kerberos/GSSAPI с реальной инфраструктурой. Они не заявлены как выполненные. Windows ARM64 и macOS M3 ранее подтверждены пользователем; новые сборки проверяются отдельно по структуре и версии.

Отдельно отложенный по запросу пользователя копирайт сопутствующих утилит остаётся без изменений.

## Windows: запуск WinSCP из меню сеанса

В 0.85-5 возвращён пункт «Запустить WinSCP» в меню окна терминала, как в оригинальном KiTTY, рядом с запуском Kageant и KiTTYgen. Задача относится только к Windows; в меню macOS и Linux этот пункт не добавлять. Реализован запуск внешнего WinSCP с параметрами текущего сеанса и сообщением, если программа не найдена.
### Исследование оригинального KiTTY

Проверено по сохранённому исходному коммиту `75fa2abcd220c17249ff7252f8d5224137001f2d`: `kitty.c`, функции `SearchWinSCP` и `StartWinSCP`, а также `docs/pages/PscpIntegration.md`.

- Основной путь задавался в `kitty.ini`, раздел `[KiTTY]`, ключ `WinSCPPath`, например `WinSCPPath=C:\Program Files\WinSCP\WinSCP.exe`. Допускалась также `.BAT`-обёртка.
- Сначала проверялся заданный файл. Если он не существовал, старый код удалял параметр и искал по очереди `%ProgramFiles%\WinSCP\WinSCP.exe`, `%ProgramFiles%\WinSCP3\WinSCP3.exe`, `WinSCP.exe` в `InitialDirectory`, затем каталог из `[KiTTY] winscpdir`. Найденный путь записывался обратно в `WinSCPPath`.
- Пункт `Start WinSCP` был доступен при найденном пути; стандартное сочетание — `Shift+F3`, переопределение — `[Shortcuts] winscp`.
- Запуск использовал текущий сеанс: протокол `WinSCPProtocol`, пользователя, адрес, порт, удалённый каталог, SSH-ключ; поддерживал `SFTPConnect`, `WinSCPOptions`, `WinSCPRawSettings` и настройки прокси.

При реализации сохранить совместимость с `WinSCPPath` и исследовать корректное разрешение относительного пути от портативного корня. Отдельно проверить пути с пробелами/кириллицей, установку в Program Files и Program Files (x86), отсутствующий файл и BAT-обёртку. Не переносить механически старые ограничения ANSI/коротких имён, удаление пользовательского параметра при временной недоступности файла и запись полного запуска с паролем в журнал. Реализовано в 0.85-5 только для Windows: меню, Shift+F3, WinSCPPath, относительный путь, поиск установленного EXE, параметры текущего SSH-сеанса и поля WinSCPOptions/WinSCPRawSettings. BAT-обёртки проверяются и отклоняются с сообщением; пароль автоматически не экспортируется.
