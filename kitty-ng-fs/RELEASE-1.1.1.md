# KiTTY-ng FS 1.1.1 — скачивание больших файлов

- Ускорено скачивание через SFTP на соединениях с задержкой: плагин держит до 32 запросов чтения одновременно вместо ожидания ответа после каждого блока 32 КиБ. Окно данных ограничено 1 МиБ.
- Сохраняется правильный порядок данных даже при перестановке ответов; короткие ответы не оставляют пропусков.
- Журнал Total Commander показывает фактически переданный объём в МиБ, в том числе до первого процента. Штатный интерфейс WFX передаёт только целый процент: для файла 8 ГБ первые примерно 82 МиБ всё ещё отображаются как 0% на шкале.
- Добавлены регрессионные проверки больших файлов, 64-битных смещений, отмены и сохранности уже существующего файла назначения.

В контролируемом тесте с задержкой ответа 20 мс скачивание 8 МиБ ускорилось с 5,4 до 0,33 с. Это результат тестового стенда, а не обещание скорости на любом сервере. Исходное зависание на конкретном пользовательском сервере не воспроизводилось; устранено подтверждённое ограничение последовательного чтения.

## Установка

Откройте `kitty-ng-fs-1.1.1-x86-x64.zip` в Total Commander, подтвердите обновление и перезапустите TC. Сохраните свой `kittyngfs.ini`. Полные исходники — в `kitty-ng-fs-1.1.1-source.zip`; SHA-256 — в `SHA256SUMS.txt`.

SSH/SFTP встроены в плагин, Klink не нужен. Основной KiTTY-ng и прежние GitHub-релизы не изменяются. Ручная проверка интерфейса TC в этом прогоне не выполнена; проверяются реальные WFX-вызовы на Windows. Подробности: [отчёт](https://github.com/nr084/KiTTY-ng/blob/kitty-ng-fs-v1.1.1/kitty-ng-fs/PUBLICATION.md).
