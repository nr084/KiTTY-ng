# KiTTY-ng FS 1.2.0

В настройках плагина Total Commander появилось поле «Права новых файлов». Указанный восьмеричный режим применяется после загрузки нового файла на SFTP-сервер. По умолчанию используется 0600. При перезаписи плагин сохраняет права существующего файла. Подсказка в диалоге объясняет права владельца, группы и остальных.

Установочный ZIP содержит модули x86 и x64. Исходники доступны отдельным архивом.
