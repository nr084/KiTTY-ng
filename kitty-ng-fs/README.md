# KiTTY-ng FS · Total Commander

**Русский** | [English](README.en.md) · [KiTTY-ng](https://github.com/nr084/KiTTY-ng)

**SFTP в панелях Total Commander через портативные сеансы KiTTY-ng.** Плагин `kitty-ng-fs` для Windows x86/x64 использует внешний Klink: одна папка профилей для терминала и файлового менеджера, без отдельного набора подключений.

Плагин выпускается отдельно от клиента. KiTTY-ng/Klink, профили и ключи в комплект не входят. Версия клиента — **0.85-6**, версия плагина — **1.0.3**.

## Точки в именах сеансов

`mail.example.ru` отображается как **mail·example·ru**. Только подпись виртуального SSH-сеанса преобразуется: Klink получает исходное имя, профили на диске не меняются, удалённый `file.tar.gz` сохраняет своё имя и расширение.

Буквальная средняя точка в исходном имени отображается как `%C2%B7`, а буквальный `%` экранируется. Поэтому разные исходные имена остаются различимы. Существующие правила суффиксов `[SSH]` при совпадении с папкой сохраняются. Старые вложенные пути и плоские закладки принимаются как совместимые псевдонимы; при неоднозначности приоритет имеет текущее отображаемое имя. После входа возвращается новый канонический путь.

## Возможности

- Вложенные группы и SSH-сеансы в сетевом окружении TC; группы идут перед подключениями при обычной сортировке с папками в начале.
- Просмотр, скачивание, загрузка, переименование, создание и удаление каталогов; Unix-права и время изменения.
- Unicode-имена, отмена операций, временные файлы перед заменой назначения.
- Запуск терминала KiTTY-ng для текущего сеанса командой `terminal`.
- Относительный путь к портативной KiTTY-ng, собственные настройки рядом с плагином.

## Установка

1. Подготовьте KiTTY-ng **0.85-6** и сохранённый SSH-сеанс. Откройте его в клиенте, проверьте ключ сервера и убедитесь, что вход работает.
2. Откройте установочный ZIP в Total Commander и подтвердите установку WFX. Для ручной установки выберите `kitty-ng-fs.wfx`; `kitty-ng-fs.wfx64` должен лежать рядом.
3. Откройте **Сетевое окружение → KiTTY-ng FS → [Настройки KiTTY-ng]** и выберите портативную папку клиента.
4. Войдите в нужную группу и сеанс. Начальный каталог `/` означает корень сервера, `.` — домашнюю папку пользователя.

Для TC x86 нужен `klink-x86.exe`, для TC x64 — `klink-x64.exe`. Требуются Windows 10/11, Unicode WFX и SFTP на сервере. Настройки сохраняются в **`kittyngfs.ini`**: прежнее имя оставлено для совместимости. При обновлении старого `kittyngfs` выберите прежнюю папку и обновите регистрацию WFX на новое имя, затем перезапустите TC; пользовательский INI не заменяйте.

## Ограничения и проверка

Нет интерактивного запроса пароля/MFA, возобновления передачи, фоновой очереди и прямого копирования между серверами. Защищённый ключ заранее загрузите в агент. Плагин не монтирует диск Windows.

## Разработка

Исходники находятся непосредственно в этом каталоге: `src/`, `assets/`, `tests/`, `tools/`. Рекомендуемая локальная сборка и проверка: `python build-local.py --toolchain C:/tools/llvm-mingw-20261020`. Альтернатива: `build-windows.cmd` (Visual Studio/CMake) либо `build-cross.sh` (LLVM-MinGW/MinGW-w64). Затем `python package.py` создаёт **два отдельных ZIP** в `dist/`. Готовые WFX предварительно должны находиться там же. Подробности сборки — в [руководстве](README.ru.md#сборка-из-исходников), команды тестов — в [tests/README.md](tests/README.md).
