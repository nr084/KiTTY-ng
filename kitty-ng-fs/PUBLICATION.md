# Выпуск kitty-ng-fs 1.1.0

Дата: 27 октября 2026. Крупное функциональное обновление по прямой команде пользователя: 1.0.3 → 1.1.0 (minor + 1, patch = 0). Основной клиент остаётся 0.85-6.

SSH/SFTP встроены в WFX; внешние Klink/Plink и отдельные криптографические DLL не нужны. Пароль, PPK, keyboard-interactive и подтверждение ключа сервера работают через Total Commander. Портативные профили, относительные ключи и видимые имена сеансов совместимы с прежними версиями. Внешние команды прокси отключены.

## Проверки

Последний stable LLVM-MinGW проверен через официальный API 27 октября: 20261020, Clang 23.1.4, UCRT. Релиз собирается локально на Windows для x86/x64. Проверяются ресурсы 1.1.0.0, реальные экспорты WFX и установка ZIP.

Полный функциональный прогон встроенного транспорта выполнен перед повышением версии: 59/59 WFX/SSH/SFTP проверок и 8/8 сценариев авторизации на каждой архитектуре; дополнительные сценарии keyboard-interactive, Unicode-группы, запрета внешнего прокси и тайм-аута — 4/4 на x64. Версионное изменение не затрагивает эту логику. Подробности: [EMBEDDED-SSH.md](EMBEDDED-SSH.md).

Ручной интерфейс TC, настоящий Kageant и все разновидности прокси не проверены. Возобновление передачи, фоновая очередь и прямое копирование сервер-сервер не реализованы. В простое SSH не обслуживается отдельным потоком; после закрытия соединения сервером может понадобиться повтор операции.

## Поставка

[Релиз 1.1.0](https://github.com/nr084/KiTTY-ng/releases/tag/kitty-ng-fs-v1.1.0): установочный ZIP x86/x64, отдельный полный исходный ZIP со встроенным ядром и SHA256SUMS.txt. Упаковка проверяет архитектуры DLL и содержимое архивов. Пользовательские профили, секреты, внешние EXE и промежуточные файлы исключены. Старые GitHub-релизы сохраняются, latest основного клиента не меняется.

# Проверка выпуска kitty-ng-fs 1.0.3

Дата: 27 октября 2026 года. Изменения только в плагине; версия основного KiTTY-ng — 0.85-6.

## Сборка

Последний стабильный LLVM-MinGW повторно проверен через официальный GitHub API: **20261020**, draft=false, prerelease=false. Использован установленный и проверенный по SHA-256 UCRT-комплект, Clang **23.1.4**. Локальная сборка Windows x86/x64, C11/O2, предупреждения как ошибки, ASLR/NX.

```powershell
python build-local.py --toolchain C:/tools/llvm-mingw-20261020 --tests session_tree icons
python package.py
```

## Ограничения

Новый интерактивный прогон Total Commander не выполнен: доступного инструмента управления Windows UI в текущей сессии нет. Проверка WFX ABI подтверждает строки, отдаваемые панели, но не является снимком экрана TC. Новая сетевая проверка не заявляется; транспорт не менялся. ASan/UBSan и MSVC в этом прогоне не использовались.
