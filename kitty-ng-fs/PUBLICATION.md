# Проверка выпуска kitty-ng-fs 1.0.3

Дата: 27 октября 2026 года. Изменения только в плагине; версия основного KiTTY-ng — 0.85-6.

## Сборка

Последний стабильный LLVM-MinGW повторно проверен через официальный GitHub API: **20261020**, draft=false, prerelease=false. Использован установленный и проверенный по SHA-256 UCRT-комплект, Clang **23.1.4**. Локальная сборка Windows x86/x64, C11/O2, предупреждения как ошибки, ASLR/NX.

```powershell
python build-local.py --toolchain C:/tools/llvm-mingw-20261020 --tests session_tree icons
python package.py
```

Новые тесты вызывают DLL каждой архитектуры нативно на Windows, без настоящего SSH-сервера. Проверено отсутствие обычной точки в видимых именах SSH-сеансов, сохранение исходных имён профилей, старые вложенные пути и плоские ссылки, различение `·`/`%`, неизменность удалённого хвоста пути.

## Ограничения

Новый интерактивный прогон Total Commander не выполнен: доступного инструмента управления Windows UI в текущей сессии нет. Проверка WFX ABI подтверждает строки, отдаваемые панели, но не является снимком экрана TC. Новая сетевая проверка не заявляется; транспорт не менялся. ASan/UBSan и MSVC в этом прогоне не использовались.
